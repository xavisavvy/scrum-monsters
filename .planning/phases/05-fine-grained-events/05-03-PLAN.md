  <action>
Create server/events/ClientEventEmitter.ts - bridges internal domain events to Socket.IO emissions.

Dependencies:
- Import Server from socket.io
- Import ScopedEventBus from ./ScopedEventBus
- Import LobbyEventSequencer from ./LobbyEventSequencer
- Import DomainEventMap from ./eventTypes

Interface ClientEventEmitterDeps:
- io: Server
- eventBus: ScopedEventBus
- sequencer: LobbyEventSequencer

Class ClientEventEmitter:
- Private fields:
  - io: Server
  - eventBus: ScopedEventBus
  - sequencer: LobbyEventSequencer

- Constructor(deps: ClientEventEmitterDeps):
  - Store dependencies
  - Call setupInternalEventListeners()

- Private setupInternalEventListeners():
  Subscribe to each internal event and emit corresponding client event:

  **Session events:**
  - 'session:player_joined' -> emit 'session:player_joined' with { playerId, playerName, team }
  - 'session:player_left' -> emit 'session:player_left' with { playerId }
  - 'session:host_changed' -> emit 'session:host_changed' with { oldHostId, newHostId, newHostName }
  - 'session:phase_changed' -> emit 'session:phase_changed' with { oldPhase, newPhase }
  - 'session:lobby_destroyed' -> call sequencer.cleanup(lobbyId), NO client emit

  **Estimation events:**
  - 'estimation:vote_cast' -> emit 'estimation:vote_cast' with { playerId, team, hasVoted: true }
    Note: Do NOT include vote value (masked until reveal)
  - 'estimation:team_consensus_reached' -> emit 'estimation:consensus_reached' with { team, consensusValue }
  - 'estimation:timer_started' -> emit 'estimation:timer_started' with { team, endsAt: startedAt + durationMs, durationMs }
  - 'estimation:timer_paused' -> emit 'estimation:timer_paused' with { team, remainingMs }
  - 'estimation:timer_resumed' -> emit 'estimation:timer_resumed' with { team, endsAt: Date.now() + remainingMs }
  - 'estimation:timer_expired' -> emit 'estimation:timer_expired' with { team, votedCount, eligibleCount }
  - 'estimation:estimate_forced' -> emit 'estimation:estimate_forced' with { team, consensusValue }
  - 'estimation:discussion_started' -> emit revealed votes for that team

  **Combat events:**
  - 'combat:boss_damaged' -> emit 'combat:boss_damaged' with { playerId, damage, newHp: bossHealth }
  - 'combat:boss_healed' -> emit 'combat:boss_healed' with { healAmount, newHp: bossHealth }
  - 'combat:boss_enraged' -> emit 'combat:boss_enraged' with { message }
  - 'combat:boss_telegraph' -> emit 'combat:boss_telegraph' with { targetId, attackType, message, delayMs }
  - 'combat:boss_defeated' -> emit 'combat:boss_defeated' with {}
  - 'combat:player_damaged' -> emit 'combat:player_damaged' with { playerId, damage, newHp: playerHealth, source }
  - 'combat:player_downed' -> emit 'combat:player_downed' with { playerId, countdownSeconds }
  - 'combat:player_revived' -> emit 'combat:player_revived' with { playerId, reviverId, newHp }
  - 'combat:revival_started' -> emit 'combat:revival_started' with { reviverId, targetId, durationMs }
  - 'combat:revival_cancelled' -> emit 'combat:revival_cancelled' with { reviverId, targetId, reason }
  - 'combat:player_entered_battle' -> emit 'combat:player_entered_battle' with { playerId }
  - 'combat:modifier_updated' -> emit 'combat:modifier_updated' with { modifier }
  - 'combat:cleanup_complete' -> call sequencer.cleanup(lobbyId), NO client emit

- Private emitToLobby(lobbyId: string, event: string, data: any):
  - Get next sequence: const seq = sequencer.nextSeq(lobbyId)
  - Add timestamp: const timestamp = Date.now()
  - Create payload: { ...data, seq, timestamp }
  - Buffer event: sequencer.bufferEvent(lobbyId, seq, event, payload)
  - Emit: io.to(lobbyId).emit(event, payload)

- Public sendFullState(lobbyId: string, lobby: Lobby, socketId?: string):
  - Get current seq (or 1 if new)
  - Create payload with seq, timestamp
  - If socketId: emit to specific socket
  - Else: emit to lobby room
  - Used for late joiners and buffer exhaustion recovery

- Public getMissedEvents(lobbyId: string, lastSeq: number): Array | null:
  - Delegate to sequencer.getMissedEvents()

- Public cleanup(lobbyId: string): void:
  - Call sequencer.cleanup(lobbyId)

Export factory function createClientEventEmitter(deps) that returns new ClientEventEmitter.
