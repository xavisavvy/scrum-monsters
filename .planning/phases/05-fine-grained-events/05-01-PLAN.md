<task type="auto">
  <name>Task 2: Implement LobbyEventSequencer</name>
  <files>server/events/LobbyEventSequencer.ts, server/events/index.ts</files>
  <action>
Create server/events/LobbyEventSequencer.ts implementing sequence number generation and event buffering.

Class LobbyEventSequencer:
- Private fields:
  - sequences: Map<string, number> (lobbyId -> current sequence)
  - buffers: Map<string, Array<{ seq, event, data, timestamp }>> (lobbyId -> circular buffer)
  - BUFFER_SIZE = 100 (approximately 30 seconds at ~3 events/sec)

- Methods:
  - nextSeq(lobbyId: string): number
    - Get current sequence (default 0), increment, store, return

  - bufferEvent(lobbyId: string, seq: number, event: string, data: any): void
    - Create entry with { seq, event, data, timestamp: Date.now() }
    - Push to buffer, shift if > BUFFER_SIZE

  - getMissedEvents(lobbyId: string, lastSeq: number): Array | null
    - Return null if lobbyId not found
    - Filter buffer for events with seq > lastSeq
    - If lastSeq < oldest buffered seq, return null (gap too large)
    - Return filtered events

  - getCurrentSeq(lobbyId: string): number
    - Return current sequence for lobby (or 0 if none)

  - cleanup(lobbyId: string): void
    - Delete sequences entry
    - Delete buffers entry

Update server/events/index.ts to export LobbyEventSequencer.
  </action>
  <verify>Run `npm run check` - LobbyEventSequencer compiles without errors</verify>
  <done>LobbyEventSequencer class exists with sequence generation, buffering, and cleanup methods</done>
