  <files>client/src/lib/stores/useEventSync.ts</files>
  <action>
Create client/src/lib/stores/useEventSync.ts - a Zustand store for sequence tracking and event processing.

Interface EventSyncState:
- lastSeq: number (last successfully processed sequence)
- pendingEvents: Map<number, { event: string, data: any }> (out-of-order events waiting)
- isRecovering: boolean (currently fetching missed events)
- pendingOptimistic: Map<string, any> (keyed by action type, stores optimistic state)

Methods:
- handleEvent(event: string, data: any & { seq: number }, socket: Socket): boolean
  - If seq === lastSeq + 1: process event, update lastSeq, check pendingEvents for next, return true
  - If seq > lastSeq + 1: gap detected, store in pendingEvents, **call requestMissedEvents(socket, lastSeq) internally**, return false
  - If seq <= lastSeq: duplicate/old event, ignore, return true
  - Process any consecutive events from pendingEvents after successful processing

  **Gap recovery is INTERNAL to handleEvent.** The caller does not need to check return value - handleEvent triggers recovery automatically when a gap is detected. Return value indicates if event was processed immediately (true) or queued due to gap (false).

- processEventQueue(): void
  - While pendingEvents has lastSeq + 1: extract, process, increment lastSeq

- requestMissedEvents(socket: Socket, lastSeq: number): void
  - If isRecovering is true, skip (already recovering)
  - Set isRecovering = true
  - Emit 'request_missed_events' with { lastSeq }

- handleMissedEventsReplay(events: Array<{ event: string, data: any }>): void
  - Process each event in order
  - Set isRecovering = false

- handleFullStateRefresh(lobby: Lobby, seq: number): void
  - Reset lastSeq to provided seq
  - Clear pendingEvents
  - Set isRecovering = false

- setOptimistic(key: string, value: any): void
  - Store in pendingOptimistic map

- clearOptimistic(key: string): void
  - Remove from pendingOptimistic map

- reconcile(key: string, serverValue: any): any
  - Compare pendingOptimistic[key] with serverValue
  - Clear optimistic, return serverValue (or merged if needed)

- reset(): void
  - Reset lastSeq to 0
  - Clear pendingEvents
  - Clear pendingOptimistic
  - Set isRecovering = false

Use Zustand create() with subscribeWithSelector middleware.

Function setupEventHandlers(socket: Socket):
- Import useEventSync and useGameState stores

**Pattern for each event handler:**
```typescript
socket.on('session:player_joined', (data) => {
  const { handleEvent } = useEventSync.getState();
  const processed = handleEvent('session:player_joined', data, socket);

  // Only apply state changes if event was processed (not queued)
  if (processed) {
    // Apply incremental update to useGameState
    const { setPlayers, lobby } = useGameState.getState();
    if (lobby) {
      const newPlayer = { id: data.playerId, name: data.playerName, team: data.team, avatar: data.avatar };
      setPlayers([...lobby.players, newPlayer]);
    }
  }
  // If not processed (gap detected), handleEvent already triggered recovery
});
```
