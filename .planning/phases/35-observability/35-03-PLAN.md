<task type="auto">
  <name>Task 1: Deploy monitoring stack to VPS and verify services</name>
  <files></files>
  <action>
Read `~/.claude/infrastructure.md` for SSH access details.

1. SSH into VPS and deploy the updated docker-compose with monitoring services:
   ```bash
   ssh -i $SSH_KEY $REMOTE_USER@$REMOTE_HOST << 'EOF'
     cd /opt/scrummonsters
     git pull origin main

     # Create prometheus config directory on VPS
     mkdir -p docker/prometheus docker/grafana/provisioning/datasources docker/grafana/provisioning/dashboards docker/grafana/dashboards

     # Add GRAFANA_ADMIN_PASSWORD to .env if not present
     grep -q GRAFANA_ADMIN_PASSWORD .env || echo "GRAFANA_ADMIN_PASSWORD=$(openssl rand -base64 16)" >> .env

     # Pull new images and start monitoring containers
     docker compose -f docker-compose.prod.yml pull prometheus grafana
     docker compose -f docker-compose.prod.yml up -d

     # Wait for services to start
     sleep 15

     # Verify all containers running
     docker compose -f docker-compose.prod.yml ps
   EOF
   ```

2. Verify Prometheus is scraping (via SSH):
   ```bash
   ssh ... "curl -s http://127.0.0.1:9090/api/v1/targets | python3 -m json.tool"
   ```
   Expected: target `app:5000` with state "up"

3. Verify /metrics endpoint returns data:
   ```bash
   ssh ... "curl -s http://127.0.0.1:5000/metrics | head -20"
   ```
   Expected: Lines containing `scrumquest_` metrics

4. Verify Grafana is running:
   ```bash
   ssh ... "curl -s http://127.0.0.1:3001/api/health"
   ```
   Expected: JSON with `"database": "ok"`

5. Verify Dozzle is running:
   ```bash
   ssh ... "curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:9999/"
   ```
   Expected: 200

6. Verify ports NOT accessible from public internet:
   ```bash
   curl -s --connect-timeout 5 http://34.199.135.244:9090/ || echo "GOOD: port 9090 not public"
   curl -s --connect-timeout 5 http://34.199.135.244:3001/ || echo "GOOD: port 3001 not public"
   curl -s --connect-timeout 5 http://34.199.135.244:9999/ || echo "GOOD: port 9999 not public"
   ```
   Expected: All three timeout/refused (not accessible)

7. Verify memory limits:
   ```bash
   ssh ... "docker stats --no-stream --format 'table {{.Name}}\t{{.MemUsage}}\t{{.MemPerc}}'"
   ```
   Expected: Prometheus < 128MB, Grafana < 128MB, Dozzle < 32MB

8. Verify Prometheus retention config:
   ```bash
   ssh ... "docker compose -f docker-compose.prod.yml exec prometheus promtool query instant http://localhost:9090 'prometheus_tsdb_retention_limit_bytes'"
   ```
   Or check via: `docker inspect` that the command args include `--storage.tsdb.retention.time=7d`
  </action>
