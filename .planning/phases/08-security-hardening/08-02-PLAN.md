<task type="auto">
  <name>Task 1: Install and Configure audit-ci for Vulnerability Scanning</name>
  <files>.audit-ci.json, package.json, .github/workflows/ci.yml</files>
  <action>
**Step 1: Install audit-ci as dev dependency**
```bash
npm install --save-dev audit-ci
```

**Step 2: Create .audit-ci.json configuration**

Create config at repo root:
```json
{
  "high": true,
  "critical": true,
  "moderate": false,
  "low": false,
  "report-type": "full",
  "advisories": [],
  "allowlist": []
}
```

Configuration explanation:
- `high: true` and `critical: true` - fail on these severities
- `moderate: false` and `low: false` - report but don't fail
- `advisories: []` - no suppressed advisories initially (add as needed with security review)
- `allowlist: []` - no allowlisted packages initially

**Step 3: Add npm script to package.json**

Add to scripts section:
```json
"audit": "audit-ci --config .audit-ci.json"
```

**Step 4: Update .github/workflows/ci.yml**

Replace the existing `security-audit` job which uses `npm audit --audit-level=high` with `continue-on-error: true`:

Find and replace:
```yaml
  security-audit:
    name: Security Audit
    runs-on: ubuntu-latest
    timeout-minutes: 10
    # Don't block PRs on audit failures, but report them
    continue-on-error: true

    steps:
      # ... existing steps ...
      - name: Run security audit
        run: npm audit --audit-level=high
```

With:
```yaml
  security-audit:
    name: Security Audit
    runs-on: ubuntu-latest
    timeout-minutes: 10
    # Block PRs on high/critical vulnerabilities (configured in .audit-ci.json)

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Run security audit
        run: npm run audit
```

CRITICAL: Remove `continue-on-error: true` - this job must now block on high/critical.

Also update the `ci-success` job to include `security-audit` in its needs array:
```yaml
  ci-success:
    name: CI Success
    runs-on: ubuntu-latest
    timeout-minutes: 5
    needs: [lint-and-typecheck, test, build, security-audit]
```

And update the check conditions:
```yaml
      - name: Check all jobs passed
        run: |
          if [[ "${{ needs.lint-and-typecheck.result }}" != "success" ]] || \
             [[ "${{ needs.test.result }}" != "success" ]] || \
             [[ "${{ needs.build.result }}" != "success" ]] || \
             [[ "${{ needs.security-audit.result }}" != "success" ]]; then
            echo "One or more jobs failed"
            exit 1
          fi
          echo "All CI checks passed!"
```
  </action>

<task type="auto">
  <name>Task 2: Configure License Compliance Scanning</name>
  <files>.licensecheckrc.json, package.json, .github/workflows/ci.yml</files>
  <action>
**Step 1: Install license-checker-rseidelsohn as dev dependency**
```bash
npm install --save-dev license-checker-rseidelsohn
```

**Step 2: Create .licensecheckrc.json configuration**

Create config at repo root for the npm script (not directly used by license-checker but documents policy):
```json
{
  "allowedLicenses": [
    "MIT",
    "Apache-2.0",
    "BSD-2-Clause",
    "BSD-3-Clause",
    "ISC",
    "0BSD",
    "Unlicense",
    "CC0-1.0"
  ],
  "excludePackages": [],
  "notes": "Permissive licenses only. Add exceptions to excludePackages with PR review."
}
```

**Step 3: Add npm script to package.json**

Add to scripts section:
```json
"license-check": "license-checker-rseidelsohn --onlyAllow 'MIT;Apache-2.0;BSD-2-Clause;BSD-3-Clause;ISC;0BSD;Unlicense;CC0-1.0' --production"
```

Note: Using --production to check only runtime dependencies. Dev dependencies with GPL won't affect distributed code since this is a web app.

**Step 4: Add license-check job to .github/workflows/ci.yml**

Add new job after security-audit:
```yaml
  license-check:
    name: License Check
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Check license compliance
        run: npm run license-check
```

Update ci-success job to include license-check:
```yaml
  ci-success:
    name: CI Success
    runs-on: ubuntu-latest
    timeout-minutes: 5
    needs: [lint-and-typecheck, test, build, security-audit, license-check]
```

And update the check conditions:
```yaml
      - name: Check all jobs passed
        run: |
          if [[ "${{ needs.lint-and-typecheck.result }}" != "success" ]] || \
             [[ "${{ needs.test.result }}" != "success" ]] || \
             [[ "${{ needs.build.result }}" != "success" ]] || \
             [[ "${{ needs.security-audit.result }}" != "success" ]] || \
             [[ "${{ needs.license-check.result }}" != "success" ]]; then
            echo "One or more jobs failed"
            exit 1
          fi
          echo "All CI checks passed!"
```
  </action>
