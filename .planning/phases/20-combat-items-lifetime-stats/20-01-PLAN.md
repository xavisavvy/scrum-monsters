  <name>Task 1: Shared item type definitions and event payloads</name>
  <files>shared/itemTypes.ts, server/events/eventTypes.ts, server/events/index.ts</files>
  <action>
Create shared/itemTypes.ts with the following definitions:

**ItemType union:** 'heal_potion' | 'damage_boost' | 'shield'

**ItemDefinition interface:**
- id: ItemType
- name: string (display name: "Heal Potion", "Damage Boost", "Shield Charm")
- description: string (short tooltip text)
- effectType: 'heal' | 'buff' | 'shield' (maps to what the item does)
- power: number (heal: 30 HP restored, damage_boost: 1.5x multiplier for 10s, shield: 50 damage absorbed)
- durationMs: number | null (null for instant effects like heal, 10000 for damage_boost, 15000 for shield)

**ITEM_DEFINITIONS constant:** Record<ItemType, ItemDefinition> with all 3 items:
- heal_potion: instant heal 30 HP
- damage_boost: 1.5x damage buff for 10 seconds
- shield: absorbs 50 damage for 15 seconds

**ItemInventory type:** Map<ItemType, number> (tracks count per item type)

**MAX_ITEMS_PER_TYPE constant:** 5 (stack limit per item type)

**Event payloads:**
- ItemAwardedPayload: { lobbyId, playerId, itemType: ItemType, newCount: number }
- ItemUsedPayload: { lobbyId, playerId, itemType: ItemType, remainingCount: number }
- ItemEffectAppliedPayload: { lobbyId, playerId, itemType: ItemType, effectType: string, value: number, durationMs: number | null, targetIds: string[] }

**Helper functions:**
- getItemDefinition(itemType: ItemType): ItemDefinition
- selectRandomItemType(): ItemType (uniformly random from the 3 types)

Register events in server/events/eventTypes.ts DomainEventMap:
- 'item:awarded': ItemAwardedPayload
- 'item:used': ItemUsedPayload
- 'item:effect_applied': ItemEffectAppliedPayload

Re-export payload types from server/events/index.ts.

<task type="auto">
  <name>Task 2: ItemManager domain with TDD (RED-GREEN)</name>
  <files>server/domains/ItemManager.ts, server/domains/ItemManager.test.ts</files>
  <action>
Follow AbilityManager.ts pattern exactly for structure. TDD: write failing tests first, then implement.

**ItemManager constructor deps (ItemManagerDeps interface):**
- eventBus: ScopedEventBus
- combatManager: { getCombatState(lobbyId): CombatState | undefined }
- getPlayerClass: (lobbyId: string, playerId: string) => AvatarClass | null

**State:** `private inventories = new Map<string, Map<string, Map<ItemType, number>>>()` (lobbyId -> playerId -> item counts)

**Public API:**

`awardItem(lobbyId, playerId, itemType?: ItemType): { awarded: boolean; itemType: ItemType }`:
- If no itemType provided, use selectRandomItemType()
- Check stack limit (MAX_ITEMS_PER_TYPE = 5). If at limit, return { awarded: false }
- Increment count in inventory
- Emit 'item:awarded' event
- Return { awarded: true, itemType }

`useItem(lobbyId, playerId, itemType: ItemType): { success: boolean; error?: string }`:
- Validate inventory has item (count > 0) -> error: 'Item not in inventory'
- Validate combat state exists via deps.combatManager.getCombatState -> error: 'Combat not active'
- Validate player combatState === 'fighting' -> error: 'Player not in combat'
- Decrement item count (remove key if count reaches 0)
- Emit 'item:used' event
- Call private applyItemEffect()
- Return { success: true }

`getInventory(lobbyId, playerId): Map<ItemType, number>` (returns copy or empty map)

`cleanupLobby(lobbyId): void` - delete inventories for lobby

`resetInventories(lobbyId): void` - clear all player inventories in lobby

**Private applyItemEffect(lobbyId, playerId, itemType):**
- Look up ITEM_DEFINITIONS[itemType]
- For heal_potion: targetIds = [playerId], effectType = 'heal', value = 30
- For damage_boost: targetIds = [playerId], effectType = 'buff', value = 1.5
- For shield: targetIds = [playerId], effectType = 'shield', value = 50
- Emit 'item:effect_applied' with { lobbyId, playerId, itemType, effectType, value, durationMs, targetIds }

**TDD Test cases (write FIRST as RED, then implement GREEN):**

1. **Inventory Management (5 tests):**
   - awardItem adds item to empty inventory
   - awardItem increments existing item count
   - awardItem respects MAX_ITEMS_PER_TYPE (returns awarded:false at 5)
   - awardItem selects random type when none specified
   - getInventory returns empty map for unknown player

2. **Item Use Validation (5 tests):**
   - useItem succeeds when player has item and is fighting
   - useItem fails when item not in inventory
   - useItem fails when combat not active
   - useItem fails when player not fighting (downed)
   - useItem decrements count and removes at 0

3. **Effect Application (3 tests):**
   - useItem emits item:used event
   - useItem emits item:effect_applied for heal_potion with correct payload
   - useItem emits item:effect_applied for damage_boost with durationMs

4. **Cleanup (3 tests):**
   - cleanupLobby removes all inventories for lobby
   - cleanupLobby doesn't affect other lobbies
   - resetInventories clears player inventories within lobby

Use vi.useFakeTimers() if needed. Mock eventBus with { emit: vi.fn(), on: vi.fn() }. Mock combatManager with getCombatState returning appropriate test states.
