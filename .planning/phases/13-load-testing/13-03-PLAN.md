  <action>
Create `.github/workflows/load-tests.yml` following project CI patterns from ci.yml.

**Workflow configuration:**
```yaml
name: Load Tests

on:
  schedule:
    - cron: '0 2 * * *'  # 2 AM UTC daily
  workflow_dispatch:
    inputs:
      run_idle_test:
        description: 'Run idle connection test (5 minutes)'
        required: false
        default: false
        type: boolean

# No concurrency group - allow scheduled and manual runs
permissions:
  contents: read

env:
  NODE_VERSION: '20'
  K6_VERSION: 'v0.52.0'
```

**Job 1: http-load-tests**
- runs-on: ubuntu-latest
- timeout-minutes: 15
- Steps:
  1. Checkout
  2. Setup Node.js (with cache)
  3. Install dependencies (npm ci)
  4. Build application (npm run build)
  5. Start application in background
  6. Wait for health check (curl --retry)
  7. Install k6 binary (download from GitHub releases)
  8. Run HTTP smoke test (continue-on-error: true)
  9. Run HTTP average load test (continue-on-error: true)
  10. Upload JSON results as artifact (retention: 30 days)
  11. Generate markdown summary

**Job 2: websocket-load-tests**
- runs-on: ubuntu-latest
- timeout-minutes: 15
- Same setup steps as http-load-tests
- Run WebSocket game flow test
- Upload results, generate summary

**Job 3: idle-connection-test (conditional)**
- runs-on: ubuntu-latest
- timeout-minutes: 10
- Condition: `if: github.event.inputs.run_idle_test == 'true' || github.event_name == 'schedule'`
- Run idle connection test (5 minutes)
- Upload results

**k6 installation step:**
```yaml
- name: Install k6
  run: |
    curl -L https://github.com/grafana/k6/releases/download/${{ env.K6_VERSION }}/k6-${{ env.K6_VERSION }}-linux-amd64.tar.gz -o k6.tar.gz
    tar -xzf k6.tar.gz
    sudo mv k6-${{ env.K6_VERSION }}-linux-amd64/k6 /usr/local/bin/
    k6 version
```

**Summary generation step:**
```yaml
- name: Generate summary
  if: always()
  run: |
    echo "## HTTP Load Test Results" >> $GITHUB_STEP_SUMMARY
    echo "" >> $GITHUB_STEP_SUMMARY
    echo "### Smoke Test (5 VUs, 30s)" >> $GITHUB_STEP_SUMMARY
    if [ -f results-http-smoke.json ]; then
      echo '```json' >> $GITHUB_STEP_SUMMARY
      tail -1 results-http-smoke.json | jq -r '.metrics | to_entries | map("\(.key): \(.value.values | to_entries | map("\(.key)=\(.value|tostring)") | join(", "))") | .[]' >> $GITHUB_STEP_SUMMARY 2>/dev/null || echo "Parse error" >> $GITHUB_STEP_SUMMARY
      echo '```' >> $GITHUB_STEP_SUMMARY
    else
      echo "No results file found" >> $GITHUB_STEP_SUMMARY
    fi
```

**continue-on-error: true** for all k6 runs - per CONTEXT.md, failures are informational only, never block.

  }
}
```

**Note:** These scripts require k6 to be installed locally:
- macOS: `brew install k6`
- Windows: `choco install k6`
- Linux: Download from https://github.com/grafana/k6/releases
