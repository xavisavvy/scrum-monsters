<objective>
Make CombatManager the single source of boss HP for basic attacks. Today two HP pools
diverge: `gameState.attackBoss` (gameState.ts:1801) drains `lobby.boss.currentHealth`
and never calls checkPhaseTransition, while `CombatManager.playerAttackBoss`
(CombatManager.ts:531) drains `combatState.boss.hp` and DOES call checkPhaseTransition
(L569) + emits combat:boss_damaged (L555). Basic attacks therefore skip phase-2/enrage
transitions, and the manual `eventBus.emit('combat:boss_damaged')` at websocket.ts:1104
would double-fire every listener once delegation lands.

Fix: rename `playerAttackBoss` → `applyBasicDamageToBoss` with richer return
`{ damage, newHp }`; route `gameState.attackBoss` dev/qa branch through it (so basic
attacks trigger checkPhaseTransition); treat `lobby.boss.currentHealth` as a projection;
and REMOVE the manual emit at websocket.ts:1104 to kill the double-emit.

Purpose: Close MAINT-05 — one boss-HP owner, correct phase transitions on basic attacks,
no double XP / double damage-boost / double client HP updates.
Output: Renamed+extended CombatManager method; delegating attackBoss; deleted manual emit;
~37-call-site test rename sweep + new regression tests.
</objective>
