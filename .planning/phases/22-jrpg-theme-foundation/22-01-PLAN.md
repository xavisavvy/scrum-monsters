Token categories (from research):

**Color tokens** — Map to existing `--retro-*` primitives where possible:
- Panel: `--jrpg-panel-bg: var(--retro-primary)`, `--jrpg-panel-bg-raised: #1d2d5a`, `--jrpg-panel-border: var(--retro-border)`, `--jrpg-panel-border-gold: #b8860b`, `--jrpg-panel-glow: var(--retro-glow)`
- Text: `--jrpg-text-primary: #f5f5f5` (12.6:1 on panel-bg), `--jrpg-text-secondary: #b0b0b0` (7.2:1), `--jrpg-text-accent: #ffd700` (9.8:1), `--jrpg-text-danger: #ff6b6b` (4.7:1), `--jrpg-text-muted: #808080` (4.6:1)
- Button: `--jrpg-btn-primary-bg: var(--retro-secondary)`, `--jrpg-btn-primary-text: #f5f5f5`, `--jrpg-btn-danger-bg: var(--retro-accent)`, `--jrpg-btn-danger-text: #ffffff`
- Stats: `--jrpg-health-high: #22c55e`, `--jrpg-health-mid: #eab308`, `--jrpg-health-low: #ef4444`, `--jrpg-xp-fill: #3b82f6`, `--jrpg-mana-fill: #8b5cf6`

**Spacing tokens:**
- `--jrpg-space-xs: 4px`, `--jrpg-space-sm: 8px`, `--jrpg-space-md: 16px`, `--jrpg-space-lg: 24px`, `--jrpg-space-xl: 32px`

**Border tokens:**
- `--jrpg-border-width: 2px`, `--jrpg-border-radius: 4px`

**Shadow tokens:**
- `--jrpg-shadow-panel: 0 0 20px var(--jrpg-panel-glow), inset 0 0 20px rgba(0,0,0,0.5)`
- `--jrpg-shadow-button: 0 0 15px var(--jrpg-panel-glow)`

**Typography tokens:**
- `--jrpg-font-primary: 'Press Start 2P', 'Courier New', monospace`
- `--jrpg-font-size-min: 12px` (minimum for Press Start 2P legibility)

**Ornamental frame CSS classes** — Add to tokens.css:
- `.jrpg-panel` — Base frame class with border, box-shadow, and inner highlight pseudo-element
- `.jrpg-panel::before` — Inner border ornament (inset 3px, 1px solid rgba white)
- `.jrpg-panel-title` — Gold accent text for panel headers

Then update `client/src/index.css` to import `tokens.css` after the existing retro.css import. Find the existing `@import './styles/retro.css'` line and add `@import './styles/tokens.css'` on the next line. Do NOT remove or modify the retro.css import.

    DEFAULT: 'var(--jrpg-panel-bg)',

    border: 'var(--jrpg-panel-border)',
    'border-gold': 'var(--jrpg-panel-border-gold)',
  },
  text: {
    DEFAULT: 'var(--jrpg-text-primary)',
    secondary: 'var(--jrpg-text-secondary)',
    accent: 'var(--jrpg-text-accent)',
    danger: 'var(--jrpg-text-danger)',
    muted: 'var(--jrpg-text-muted)',
  },
  btn: {
    primary: 'var(--jrpg-btn-primary-bg)',
    'primary-text': 'var(--jrpg-btn-primary-text)',
    danger: 'var(--jrpg-btn-danger-bg)',
    'danger-text': 'var(--jrpg-btn-danger-text)',
  },
  health: {
    high: 'var(--jrpg-health-high)',
    mid: 'var(--jrpg-health-mid)',
