**retro-card.tsx** — Replace the existing implementation with a thin re-export wrapper. The current file exports `RetroCard` as a named export (function component). The new version should:

1. Import `GamePanel` and its props type from `./GamePanel`
2. Create `RetroCard` as a wrapper that passes all props through to `GamePanel`
3. Map the existing `RetroCardProps` interface (children, className, title) to `GamePanel` props
4. Export `RetroCard` as named export AND re-export `GamePanel` for new code that wants to import from this path

The key mapping: RetroCard always used `retro-card` CSS class. GamePanel uses `jrpg-panel` CSS class from tokens.css. The wrapper should pass className through — the `jrpg-panel` base class is built into GamePanel's CVA definition.

```typescript
import { GamePanel, type GamePanelProps } from './GamePanel';

interface RetroCardProps {
  children: React.ReactNode;
  className?: string;
  title?: string;
}

export function RetroCard({ children, className, title }: RetroCardProps) {
  return (
    <GamePanel className={className} title={title}>
      {children}
    </GamePanel>
  );
}

// Re-export for gradual migration
export { GamePanel } from './GamePanel';
```

**retro-button.tsx** — Same pattern. Replace existing implementation with wrapper:

1. Import `GameButton` from `./GameButton`
2. Create `RetroButton` as a React.forwardRef wrapper that maps old variant names to new ones
3. The existing variants are `primary | secondary | accent` — map them to GameButton's `primary | secondary | danger`
4. Preserve the `React.forwardRef` pattern and `displayName`

```typescript
import React from 'react';
import { GameButton, type GameButtonProps } from './GameButton';

interface RetroButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'accent';
  size?: 'sm' | 'md' | 'lg';
}

const variantMap: Record<string, GameButtonProps['variant']> = {
  primary: 'primary',
  secondary: 'secondary',
  accent: 'danger',
};

export const RetroButton = React.forwardRef<HTMLButtonElement, RetroButtonProps>(
  ({ variant = 'primary', ...props }, ref) => (
    <GameButton ref={ref} variant={variantMap[variant] ?? 'primary'} {...props} />
  )
);

RetroButton.displayName = "RetroButton";

// Re-export for gradual migration
export { GameButton } from './GameButton';
```
