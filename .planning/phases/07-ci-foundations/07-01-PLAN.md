2. Update `vitest.config.ts` coverage configuration:
   - Add "json-summary" to reporter array (required for coverage report action)
   - Add thresholds block with measured baseline values (use floor of current coverage)
   - Keep existing include/exclude patterns

Example thresholds block:
```typescript
thresholds: {
  lines: XX,       // Set to floor of measured line coverage
  branches: XX,    // Set to floor of measured branch coverage
  functions: XX,   // Set to floor of measured function coverage
  statements: XX,  // Set to floor of measured statement coverage
}
```

The thresholds should be set to the CURRENT coverage (rounded down to nearest integer), NOT aspirational targets. This creates a floor that prevents regression without blocking existing PRs.

3. Run `npm run test:coverage` again to verify thresholds pass.

4. Verify `coverage/coverage-summary.json` is generated (needed by coverage report action).
