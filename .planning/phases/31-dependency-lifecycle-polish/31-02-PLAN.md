  <name>Task 1: Configure ARGOCD_AUTH_TOKEN GitHub secret</name>
  <action>
This task requires human action. Claude cannot configure GitHub repository secrets.

**What needs to happen:**

1. Generate an ArgoCD API token from your ArgoCD server:
   - Log in to ArgoCD UI (or use `argocd account generate-token --account <service-account>`)
   - Create a token for the service account used by CI/CD
   - The token should have permissions to: sync applications, get application status, rollback applications

2. Add the token as a GitHub repository secret:
   - Go to: GitHub repo → Settings → Secrets and variables → Actions
   - Click "New repository secret"
   - Name: `ARGOCD_AUTH_TOKEN`
   - Value: (paste the ArgoCD API token)
   - Click "Add secret"

3. Verify the secret is referenced correctly in workflows:
   - `.github/workflows/rollback.yml` — used in 6 places across rollback, verify, and notification jobs
   - `.github/workflows/deploy.yml` — used in 3 places for sync and wait operations
   - `.github/workflows/auto-rollback-monitor.yml` — used in 1 place for automatic rollback

**Note:** If ArgoCD is not yet deployed in production, this secret can be configured with a placeholder value and updated when ArgoCD is deployed. The workflows only run on manual dispatch (`workflow_dispatch`), so a placeholder won't cause unexpected failures.
  </action>
  <verify>
