2. Add a `restart_game` handler immediately after the `abandon_quest` handler block, following the exact same pattern:
   ```typescript
   socket.on('restart_game', () => {
     socketLogger.debug('Server received restart_game event');
     const playerId = socket.data.playerId;
     if (!playerId) {
       socketLogger.debug('No playerId found for restart_game');
       return;
     }

     socketLogger.debug({ playerId }, 'Processing restart_game for player');
     const lobby = gameState.abandonQuest(playerId);
     if (lobby) {
       gameLogger.info({ lobbyId: lobby.id, newPhase: lobby.gamePhase }, 'Game restarted (new game)');
       io.to(lobby.id).emit('lobby_updated', { lobby });
     }
   });
   ```
3. This reuses `abandonQuest` which resets gamePhase to 'lobby', clears currentTicket/boss/completedTickets, resets player scores/states, but preserves `lobby.tickets` (backlog). This is exactly the correct "New Game" behavior per research.
