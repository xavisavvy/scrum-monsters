  <name>Lobby Lifecycle Methods</name>
  <files>server/domains/SessionManager.ts, server/domains/SessionManager.test.ts</files>
  <behavior>
TDD the following behaviors:

**createLobby(hostName, lobbyName, options?)**
- Creates new Lobby with unique ID (6 chars uppercase, or custom if provided)
- Creates host Player with isHost: true, team: 'spectators'
- Initializes playerCombatStates and playerPositions for host
- Stores lobby in lobbies Map, playerId in playerToLobby Map
- Emits 'session:player_joined' event with lobbyId, playerId, playerName
- Returns the created Lobby

**joinLobby(lobbyId, playerName)**
- Throws LobbyNotFoundError if lobbyId doesn't exist
- Creates new Player with isHost: false, team: 'developers'
- Adds player to lobby.players array
- Initializes playerCombatStates and playerPositions for new player
- Updates team assignments
- Stores playerId in playerToLobby Map
- Emits 'session:player_joined' event
- Returns { lobby, player }

**getLobby(lobbyId)** - Returns lobby or null
**getPlayerLobby(playerId)** - Returns player's lobby or null

**removePlayer(playerId)**
- Removes player from lobby.players
- Cleans up playerCombatStates, playerPositions, playerToLobby
- Updates team assignments
- Emits 'session:player_left' event
- If last player, destroys lobby and emits 'session:lobby_destroyed'
- If host leaves, transfers host to next player (basic, activity-based in later plan)
- Returns updated lobby or null if destroyed

Test cases:
- createLobby returns lobby with correct structure
- createLobby with custom ID uses that ID
- createLobby emits session:player_joined
- joinLobby adds player to existing lobby
- joinLobby throws LobbyNotFoundError for invalid ID
- joinLobby emits session:player_joined
- getLobby returns lobby for valid ID
- getLobby returns null for invalid ID
- getPlayerLobby returns lobby for valid player
- getPlayerLobby returns null for unknown player
- removePlayer removes from lobby
- removePlayer emits session:player_left
- removePlayer destroys empty lobby
- removePlayer transfers host when host leaves
  </behavior>
