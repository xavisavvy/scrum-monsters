  <behavior>
TDD the following behaviors:

**generateReconnectToken(playerId, lobbyId, playerName): string**
- Creates token payload with playerId, lobbyId, playerName, issuedAt, expiresAt
- Signs payload with HMAC-SHA256 using TOKEN_SECRET
- Base64 encodes full token (payload + signature)
- Stores token in reconnectTokens Map
- Returns token string

**validateReconnectToken(tokenString): ReconnectToken | null**
- Retrieves token from reconnectTokens Map
- Returns null if not found
- Checks expiry (5 minutes per CONTEXT.md)
- Verifies signature matches
- Returns null and deletes token if expired or invalid
- Returns valid ReconnectToken on success

**handlePlayerDisconnect(playerId): { disconnectedPlayer, reconnectToken, hostTransfer? } | null**
- Returns null if player not in a lobby
- Creates DisconnectedPlayer record with:
  - disconnectedAt: current time
  - graceExpiresAt: current time + DISCONNECT_GRACE_PERIOD (10 min)
  - lastKnownPosition and lastKnownCombatState (from lobby)
- Generates reconnect token
- Stores in disconnectedPlayers Map
- If host disconnects, triggers promoteNewHost (basic - first connected player)
- Emits 'session:player_disconnected' event
- Returns { disconnectedPlayer, reconnectToken, hostTransfer? }

**attemptPlayerReconnect(tokenString): ReconnectResponse**
- Validates token (returns 'invalid_token' if fails)
- Checks lobby still exists (returns 'lobby_closed' if not)
- Checks disconnectedPlayer record exists and not expired (returns 'grace_expired' if not)
- Finds player in lobby
- Restores lastKnownPosition and lastKnownCombatState
- Generates new reconnect token
- Cleans up old token and disconnectedPlayer record
- Returns { result: 'success', lobbySync: LobbySync, message }

**processDisconnectedPlayers(): void**
- Called periodically (by watchdog timer)
- Iterates disconnectedPlayers Map
- Removes players where graceExpiresAt < now
- Calls removePlayer for expired players
- Cleans up expired tokens
