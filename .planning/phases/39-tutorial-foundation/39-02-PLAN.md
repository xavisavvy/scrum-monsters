**Create `client/src/components/tutorial/SpotlightMask.tsx`:**

Props: `{ targetRect: { top, left, width, height } | null; visible: boolean; padding?: number; onClickOverlay?: () => void }`

- Renders a `fixed inset-0 z-[100]` container with `pointer-events-auto`.
- Inside: an SVG at 100% width/height with a mask element. The mask has a white rect filling the whole SVG and a black rect positioned at (targetRect.left - padding, targetRect.top - padding) with size (targetRect.width + padding*2, targetRect.height + padding*2), rx=8. The visible rect uses fill="rgba(0,0,0,0.75)" with mask="url(#spotlight-mask)".
- Default padding: 8.
- Wrap in framer-motion AnimatePresence. The container is motion.div with initial/animate/exit opacity 0->1->0, duration 0.3.
- Use `useReducedMotion()` from framer-motion. If reduced motion, set transition duration to 0 (instant appear/disappear, but still render the mask since it is functional, not decorative).
- Only render when visible AND targetRect are truthy.
- onClick on the overlay div calls onClickOverlay if provided.

**Create `client/src/components/tutorial/HintBubble.tsx`:**

Props: `{ targetRect: { top, left, width, height, bottom, right } | null; text: string; position?: 'top' | 'bottom' | 'left' | 'right'; onNext?: () => void; onDismiss?: () => void; stepLabel?: string }`

- Calculates absolute position based on position prop (default 'bottom'):
  - bottom: top = targetRect.bottom + 12, left = centerX, transform translateX(-50%)
  - top: top = targetRect.top - 12, left = centerX, transform translate(-50%, -100%)
  - right: top = targetRect vertical center, left = targetRect.right + 12, transform translateY(-50%)
  - left: top = targetRect vertical center, left = targetRect.left - 12, transform translate(-100%, -50%)
- Renders as motion.div at fixed z-[101] with max-w-xs.
- Initial: opacity 0, scale 0.9. Animate: opacity 1, scale 1. Exit: opacity 0, scale 0.9. Use useReducedMotion -- if preferred, set transition duration to 0.
- Inner styling: JRPG-themed -- bg-gray-900/95 border-2 border-amber-500/60 rounded-lg p-4 shadow-lg shadow-amber-500/10. Text in text-sm text-gray-100.
- If stepLabel provided, show it as text-xs text-amber-400/70 mb-1 above the text.
- Show "Skip" button (calls onDismiss) if onDismiss provided. Show "Next" or "Got it" button (calls onNext) if onNext provided. Buttons styled: Skip = text-xs text-gray-400 hover:text-gray-200, Next = text-xs text-amber-400 hover:text-amber-300 font-bold. Buttons in a flex gap-2 mt-3 justify-end container.
- Only render when targetRect is truthy.

**Create `client/src/components/tutorial/TutorialOverlay.tsx`:**

This is the orchestrator that connects the store to the visual components. It does NOT define tutorial content (that is Phase 40). It provides the rendering shell.

Props: none (reads from useTutorial store directly).

- Import and use useTutorial store: read activeTutorial, activeStep, isSpotlightVisible, isHydrated.
- Import and use useHintTarget hook.
- Hydration guard: If !isHydrated, render nothing (return null). This prevents tutorial flash on page load.
- No active tutorial guard: If !activeTutorial, render nothing.
- For now (no content yet), the component defines a placeholder TUTORIAL_STEPS constant -- an empty Record of string to TutorialStep[] where TutorialStep = { targetId: string; text: string; position?: 'top'|'bottom'|'left'|'right' }. Export the TutorialStep type for Phase 40 to use.
- When activeTutorial changes or activeStep changes, call locateTarget(currentStep.targetId) to position overlays. Use a useEffect with a 350ms delay (via setTimeout) to wait for PhaseTransition animations to complete before locating. Clean up the timeout on unmount/re-run.
- Render SpotlightMask with targetRect and isSpotlightVisible.
- Render HintBubble with targetRect, text from current step, position from current step. onNext calls advanceStep() (or completeTutorial(activeTutorial) if on last step). onDismiss calls completeTutorial(activeTutorial) to skip.
- Show stepLabel as "Step N of M" if steps.length > 1.
- Wrap both in a Fragment. Do NOT wrap in AnimatePresence here -- each component has its own AnimatePresence internally.
