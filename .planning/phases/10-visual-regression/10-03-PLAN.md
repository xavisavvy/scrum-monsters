<task type="auto">
  <name>Task 1: Create visual regression CI workflow</name>
  <files>.github/workflows/visual-regression.yml</files>
  <action>
Create GitHub Actions workflow for visual regression testing.

**Key requirements from CONTEXT.md:**
- Docker container for consistent rendering (mcr.microsoft.com/playwright:v1.49.1-noble)
- Visual failures block PR merge (exit 1 on failure)
- Upload diff report as artifact on failure
- PR comment with link to artifacts
- Retry 2 times (match existing playwright config)

```yaml
name: Visual Regression

on:
  pull_request:
    branches: [main]
    paths-ignore:
      - "**.md"
      - "docs/**"
      - ".github/ISSUE_TEMPLATE/**"
      - ".github/DISCUSSION_TEMPLATE/**"

concurrency:
  group: visual-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read
  pull-requests: write

jobs:
  visual-tests:
    name: Visual Regression Tests
    runs-on: ubuntu-latest
    container:
      image: mcr.microsoft.com/playwright:v1.49.1-noble
      options: --init --ipc=host

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Install dependencies
        run: npm ci

      - name: Run visual regression tests
        id: visual-tests
        run: npm run test:visual
        continue-on-error: true

      - name: Upload visual diff report
        uses: actions/upload-artifact@v4
        if: steps.visual-tests.outcome == 'failure'
        with:
          name: visual-diff-report
          path: playwright-report/
          retention-days: 7

      - name: Upload test results with diffs
        uses: actions/upload-artifact@v4
        if: steps.visual-tests.outcome == 'failure'
        with:
          name: visual-test-results
          path: test-results/
          retention-days: 7

      - name: Comment PR on failure
        if: steps.visual-tests.outcome == 'failure'
        uses: actions/github-script@v7
        with:
          script: |
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: `### Visual Regression Tests Failed

            Screenshots differ from baselines. Please review the changes:

            1. [Download diff report](${process.env.GITHUB_SERVER_URL}/${process.env.GITHUB_REPOSITORY}/actions/runs/${process.env.GITHUB_RUN_ID}) (Artifacts section)
            2. If changes are intentional: \`npm run test:visual:update\` and commit updated baselines
            3. If changes are unintentional: Fix the UI regression

            See [visual testing docs](https://playwright.dev/docs/test-snapshots) for more info.`
            })

      - name: Fail if tests failed
        if: steps.visual-tests.outcome == 'failure'
        run: exit 1
```
  </action>

**Create .github/workflows/label.yml if it doesn't exist:**
```yaml
name: Label PRs

on:
  pull_request:
    types: [opened, synchronize]

permissions:
  contents: read
  pull-requests: write

jobs:
  label:
    name: Auto-label PRs
    runs-on: ubuntu-latest
    steps:
      - uses: actions/labeler@v5
        with:
          repo-token: ${{ secrets.GITHUB_TOKEN }}
```
