<objective>
Fix the server-side root cause of the Phase 41 reconnection bug:

1. **Immediate host transfer on disconnect.** `SessionManager.handlePlayerDisconnect` (research lines 700-724) transfers host status the instant the host's socket disconnects. There is no symmetric restoration path in `attemptPlayerReconnect` (research lines 745-845). A host who disconnects briefly (network blip, server restart, mobile tab switch) and reconnects within the 10-minute grace period is permanently demoted.

2. **Token expiry shorter than grace period.** `TOKEN_EXPIRY_TIME = 5min` while `DISCONNECT_GRACE_PERIOD = 10min` (research lines 78-80). A player can be in the valid grace window yet hold a structurally expired token, producing `invalid_token` failures despite legitimate reconnect intent.

Strategy:
- Defer host transfer until grace expiry. Set `wasHost: true` on the DisconnectedPlayer record at disconnect time. Move the actual `lobby.hostId = newHost.id` mutation into `processDisconnectedPlayers` (the grace-expiry sweeper).
- Restore host on successful reconnect. In `attemptPlayerReconnect`, if `disconnectedPlayer.wasHost === true`, set `player.isHost = true` and `lobby.hostId = playerId` (rolling back any interim transfer).
- Widen `TOKEN_EXPIRY_TIME` to equal `DISCONNECT_GRACE_PERIOD` (10 min). This trades a slightly larger replay window for grace/token alignment — acceptable given tokens are signed with `SESSION_SECRET` and bound to a specific playerId/lobbyId pair.

Final task is a checkpoint that runs the live repro from the ROADMAP.

Out of scope (deferred): persisting `reconnectTokens` Map across server restarts (Redis), multi-tab races. The post-restart "all in-memory tokens lost" case is fully handled by Plan 41-01's client-side coherence guard.

Purpose: Closes ROADMAP success criteria 2 (no duplicate self), 3 (host preserved), 4 (token invalidated correctly), 5 (closed regression).

Output: A reconnect path that preserves identity and host status across the grace window; tests prove deferred transfer + restoration; the live repro passes.
</objective>
