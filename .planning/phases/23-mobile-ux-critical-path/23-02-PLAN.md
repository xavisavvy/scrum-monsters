<objective>
Cap Three.js Canvas DPR at 2 and add adaptive quality scaling via PerformanceMonitor to prevent mobile GPU overheating and maintain acceptable FPS on mid-range phones.

Purpose: Modern phones have DPR 3-4 (9-16x pixel overdraw vs standard). Uncapped DPR causes thermal throttling and battery drain. PerformanceMonitor from drei dynamically adjusts quality based on actual measured FPS.
Output: Lobby.tsx Canvas with dpr cap, PerformanceMonitor adaptive quality, conditional antialias.
</objective>

     dpr={dpr}
     gl={{ antialias: !isMobile, alpha: true }}
   >
     <PerformanceMonitor
       onDecline={() => setDpr((d) => Math.max(d - 0.5, 1))}
       onIncline={() => setDpr((d) => Math.min(d + 0.5, 2))}

       <Suspense fallback={null}>

       </Suspense>
     </PerformanceMonitor>

   - `<PerformanceMonitor>` wraps children — monitors FPS and adjusts DPR down if performance degrades, back up if it recovers. Uses drei defaults: 250ms collection window, 10 iterations, 0.75 threshold.
