<task type="auto">
  <name>Task 1: Add safe-area padding to ReconnectionStatus and fix touch targets</name>
  <files>
    client/src/components/ui/ReconnectionStatus.tsx
  </files>
  <action>
Modify `client/src/components/ui/ReconnectionStatus.tsx`:

1. **Add safe-area top padding to the banner container:**
   The banner is `fixed top-4 left-1/2 ... z-50`. On devices with notches, `top-4` (16px) may be obscured. Add safe-area padding:
   - Change the outer div style to include safe-area offset. Use inline style since Tailwind doesn't support env() natively:
   ```tsx
   <div
     className="fixed left-1/2 transform -translate-x-1/2 z-50 min-w-[320px] max-w-md"
     style={{ top: 'calc(16px + env(safe-area-inset-top, 0px))' }}
   >
   ```
   - The `env(safe-area-inset-top, 0px)` has a fallback of 0px for devices without notches.
   - Remove the `top-4` Tailwind class since the inline style replaces it.

2. **Fix touch targets on action buttons:**
   The Retry and Dismiss buttons use `RetroButton` with `size="sm"` and additional `className="text-xs px-3 py-1"`. The `py-1` overrides min-height and makes these ~28px tall. Fix:
   - Change `className="text-xs px-3 py-1"` to `className="text-xs px-3 py-2 min-h-[44px]"` on both the Retry Now and Dismiss buttons.
   - This ensures the reconnection action buttons meet touch target requirements.

3. **Ensure banner width works on small mobile screens:**
   The banner has `min-w-[320px]`. On very small phones (320px width like iPhone SE), this causes horizontal overflow. Change to:
   - `min-w-[280px] max-w-[calc(100vw-32px)]` — max-width ensures 16px margin on each side.
   - Or simpler: add `w-[calc(100vw-32px)] max-w-md` to make it responsive.
  </action>

- Grep for `min-h-\[44px\]` in ReconnectionStatus.tsx returns matches (for buttons)
- Grep for `top-4` in ReconnectionStatus.tsx returns no match (replaced by inline style)
  </verify>
  <done>
- ReconnectionStatus banner positioned below notch via safe-area-inset-top
- Retry and Dismiss buttons have 44px minimum touch target
- Banner width is responsive for small mobile screens
  </done>
