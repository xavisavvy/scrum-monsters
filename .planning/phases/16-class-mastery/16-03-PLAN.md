Create `client/src/lib/stores/useClassMastery.tsx` following the `useProgression` pattern:

1. Import types from `@shared/progressionTypes`: `ClassMasteryEntry`, `ClassMasteryData`, `MASTERY_TIER_NAMES`, `MASTERY_THRESHOLDS`

2. Define store interface:
   ```typescript
   interface PendingTierUp {
     id: string;
     playerId: string;
     playerName: string;
     avatarClass: string;
     oldTier: number;
     newTier: number;
     triggeredAt: number;
   }

   interface ClassMasteryState {
     // State
     masteryData: ClassMasteryData;  // Current player's mastery data
     lobbyMasteryData: Record<string, ClassMasteryData>;  // All players in lobby (keyed by playerId)
     pendingTierUps: PendingTierUp[];  // Queue for celebration display
     isLoaded: boolean;

     // Actions
     handleMasterySync: (data: { masteryData: ClassMasteryData }) => void;
     handleMasteryXPAwarded: (data: { playerId: string; avatarClass: string; amount: number; newTotal: number }) => void;
     handleTierUp: (data: { playerId: string; playerName: string; avatarClass: string; oldTier: number; newTier: number }) => void;
     clearTierUp: (id: string) => void;
     setLobbyPlayerMastery: (playerId: string, data: ClassMasteryData) => void;
     reset: () => void;
   }
   ```

3. Create store with `subscribeWithSelector` middleware (same as useProgression)

4. Key behaviors:
   - `handleMasterySync`: Set full mastery data + isLoaded flag (called on join/reconnect)
   - `handleMasteryXPAwarded`: Update specific class's totalXP in masteryData
   - `handleTierUp`: Update class tier + add to pendingTierUps queue
   - `clearTierUp`: Remove from pendingTierUps (after celebration displays)
   - `setLobbyPlayerMastery`: Track other players' mastery for lobby display
   - `reset`: Clear all state

5. Add helper function `getTierForClass(masteryData: ClassMasteryData, avatarClass: string): number` that looks up tier from data (returns 0 if class not found).

6. Add helper `getProgressToNextTier(totalXP: number, currentTier: number): { current: number; needed: number; percentage: number }` that calculates progress within current tier toward next tier.

Write basic tests in `useClassMastery.test.ts`:
- Store initializes with empty state
- handleMasterySync sets data and isLoaded
- handleMasteryXPAwarded updates specific class XP
- handleTierUp adds to pendingTierUps queue
- clearTierUp removes specific tier-up from queue
- reset clears all state
