   - Find where player combat state is initialized (when player enters battle / combat starts)
   - After setting base HP and damage values, apply mastery bonuses:
     ```typescript
     const masteryBonuses = this.deps.getPlayerMasteryBonuses?.(playerId, playerClass);
     if (masteryBonuses) {
       const { combatBonuses } = masteryBonuses;
       // Apply HP bonus
       const baseHP = playerCombatState.maxHp;
       playerCombatState.maxHp = Math.floor(baseHP * (1 + combatBonuses.hpPercent / 100));
       playerCombatState.hp = playerCombatState.maxHp; // Start at full HP
       // Store damage bonus for use in damage calculations
       playerCombatState.damageModifier = 1 + combatBonuses.damagePercent / 100;
     }
     ```
