  <files>specs/openapi.yaml</files>
  <action>
Create `specs/openapi.yaml` with OpenAPI 3.1 specification documenting all REST endpoints:

**Info section:**
- title: ScrumQuest API
- version: 1.0.0
- description: Real-time multiplayer scrum poker estimation game API

**Servers:**
- url: http://localhost:5000 (development)
- url: https://scrumquest.app (production placeholder)

**Tags (organize by purpose):**
- health: Health check endpoints
- auth: Authentication endpoints
- user: User profile and data endpoints

**Paths to document (all from server/routes.ts, auth/routes.ts, profileRoutes.ts):**

1. `GET /api/health` - Health check
   - 200: { status: 'ok', timestamp: ISO8601 }

2. `GET /api/ws-health` - WebSocket health check
   - 200: { status: 'ok', websocket: {...}, timestamp }
   - 503: { status: 'error', message, timestamp }

3. `GET /api/auth/me` - Get current user
   - 200: { user: User | null }

4. `POST /api/auth/register` - Register user
   - Request: { email, password, username?, displayName? }
   - 201: { user: User }
   - 400: { error: string } (validation errors)
   - 500: { error: string }

5. `POST /api/auth/login` - Login
   - Request: { email, password }
   - 200: { user: User }
   - 401: { error: string }
   - 500: { error: string }

6. `POST /api/auth/logout` - Logout
   - 200: { success: true }
   - 500: { error: string }

7. `GET /api/auth/providers` - List OAuth providers
   - 200: { google: boolean, github: boolean, local: boolean }

8. `GET /api/user/profile` - Get user profile (authenticated)
   - 200: { profile: UserProfile }
   - 401: { error: 'Not authenticated' }
   - 500: { error: string }

9. `PUT /api/user/profile` - Update user profile (authenticated)
   - Request: { preferredAvatar?, preferredTeam?, audioEnabled?, musicVolume?, sfxVolume?, settings? }
   - 200: { profile: UserProfile }
   - 400: { error: string }
   - 401: { error: 'Not authenticated' }
   - 500: { error: string }

10. `GET /api/user/stats` - Get user stats (authenticated)
    - 200: { stats: UserStats }
    - 401: { error: 'Not authenticated' }
    - 500: { error: string }

11. `GET /api/user/history` - Get estimation history (authenticated)
    - Query: limit (optional, max 100)
    - 200: { history: EstimationHistory[] }
    - 401: { error: 'Not authenticated' }
    - 500: { error: string }

12. `GET /api/user/accounts` - Get OAuth accounts (authenticated)
    - 200: { accounts: OAuthAccount[] }
    - 401: { error: 'Not authenticated' }
    - 500: { error: string }

13. `PUT /api/user/display-name` - Update display name (authenticated)
    - Request: { displayName: string }
    - 200: { user: User }
    - 400: { error: string }
    - 401: { error: 'Not authenticated' }
    - 404: { error: 'User not found' }
    - 500: { error: string }

**Components/Schemas (reusable types):**
- User: { id, username, email, displayName, avatarUrl }
- UserProfile: { userId, preferredAvatar?, preferredTeam?, audioEnabled?, musicVolume?, sfxVolume?, settings?, createdAt, updatedAt }
- UserStats: { userId, totalEstimations, totalSessions, averageScore, ... }
- OAuthAccount: { id, provider, createdAt }
- Error: { error: string }
- TeamType: enum ['developers', 'qa', 'spectators']

**Components/Responses (reusable responses):**
- Unauthorized: 401 with Error schema
- InternalError: 500 with Error schema
- BadRequest: 400 with Error schema

**Security:**
- cookieAuth: Session cookie (connect.sid)

Note: OAuth callback routes (/api/auth/google/callback, /api/auth/github/callback) and page redirect routes (/join/:id, /room/:id, /marketing, etc.) are excluded as they return HTML redirects, not JSON API responses. The /metrics endpoint is excluded as it returns Prometheus text format, not JSON.

<task type="auto">
  <name>Task 2: Configure Spectral linting and type generation</name>
  <files>specs/.spectral.yaml, package.json, .gitattributes</files>
  <action>
**Create `specs/.spectral.yaml`:**
```yaml
extends:
  - spectral:oas

rules:
  # Require operationId on all operations
  operation-operationId: error

  # Require descriptions
  operation-description: warn
  info-description: error

  # Validate examples against schemas
  oas3-valid-schema-example: error

  # Require tags on operations
  operation-tags: warn
```

**Update `package.json` scripts:**
Add these scripts (merge with existing):
```json
{
  "scripts": {
    "generate:api-types": "openapi-typescript specs/openapi.yaml -o shared/api-types.generated.ts",
    "lint:api-spec": "spectral lint specs/openapi.yaml --ruleset specs/.spectral.yaml",
    "validate:api-spec": "npm run lint:api-spec && npm run generate:api-types"
  }
}
```

**Install dev dependencies:**
```bash
npm install --save-dev openapi-typescript @stoplight/spectral-cli
```

**Update `.gitattributes`** (create if not exists, append if exists):
```
# Mark generated files
shared/api-types.generated.ts linguist-generated=true
```

This marks the generated types file so GitHub treats it as generated (collapsed in diffs, excluded from language statistics).
