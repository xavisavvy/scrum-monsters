<task type="auto">
  <name>Task 2: Create API contracts CI workflow</name>
  <files>.github/workflows/api-contracts.yml</files>
  <action>
Create `.github/workflows/api-contracts.yml`:

```yaml
name: API Contract Testing

on:
  pull_request:
    paths:
      - 'server/**'
      - 'shared/**'
      - 'specs/**'
      - 'package.json'
      - '.github/workflows/api-contracts.yml'
  push:
    branches: [main]
    paths:
      - 'server/**'
      - 'shared/**'
      - 'specs/**'

jobs:
  validate-specs:
    name: Validate API Specs
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Lint OpenAPI spec
        run: npm run lint:api-spec

      - name: Lint AsyncAPI spec
        run: npm run lint:asyncapi-spec

  type-drift:
    name: Check Type Generation Drift
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Regenerate types from spec
        run: npm run generate:api-types

      - name: Check for uncommitted changes
        run: |
          if [[ -n $(git status --porcelain shared/api-types.generated.ts) ]]; then
            echo "::error::Generated types differ from committed types. Run 'npm run generate:api-types' and commit."
            git diff shared/api-types.generated.ts
            exit 1
          fi
          echo "Types are up to date with spec."

  contract-tests:
    name: Contract Tests
    runs-on: ubuntu-latest
    needs: validate-specs
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'
          cache-dependency-path: 'requirements-schemathesis.txt'

      - name: Install Node dependencies
        run: npm ci

      - name: Install Schemathesis
        run: pip install -r requirements-schemathesis.txt

      - name: Build application
        run: npm run build

      - name: Start server
        run: |
          npm run start &
          echo $! > server.pid
          # Wait for server to be ready
          timeout 60 bash -c 'until curl -s http://localhost:5000/api/health > /dev/null; do sleep 1; done'
        env:
          NODE_ENV: production
          PORT: 5000

      - name: Run contract tests
        run: |
          schemathesis run specs/openapi.yaml \
            --base-url=http://localhost:5000 \
            --checks all \
            --hypothesis-max-examples=20 \
            --hypothesis-seed=42 \
            --workers 1 \
            --report \
            --junit-xml=schemathesis-report.xml \
            || SCHEMATHESIS_EXIT_CODE=$?

          # Stop server
          kill $(cat server.pid) 2>/dev/null || true

          # Exit with Schemathesis exit code
          exit ${SCHEMATHESIS_EXIT_CODE:-0}

      - name: Upload test report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: schemathesis-report
          path: schemathesis-report.xml
          retention-days: 7

      - name: Publish test results
        if: always()
        uses: mikepenz/action-junit-report@v4
        with:
          report_paths: 'schemathesis-report.xml'
          check_name: 'Contract Test Results'
          fail_on_failure: true

  # Gate job for branch protection
  api-contracts-success:
    name: API Contracts Success
    runs-on: ubuntu-latest
    needs: [validate-specs, type-drift, contract-tests]
    if: always()
    steps:
      - name: Check all jobs passed
        run: |
          if [[ "${{ needs.validate-specs.result }}" != "success" ]]; then
            echo "Spec validation failed"
            exit 1
          fi
          if [[ "${{ needs.type-drift.result }}" != "success" ]]; then
            echo "Type drift check failed"
            exit 1
          fi
          if [[ "${{ needs.contract-tests.result }}" != "success" ]]; then
            echo "Contract tests failed"
            exit 1
          fi
          echo "All API contract checks passed!"
```

**Key design decisions:**

1. **Three-job structure:**
   - `validate-specs`: Fast linting check (runs first)
   - `type-drift`: Ensures generated types match spec
   - `contract-tests`: Full Schemathesis validation against running server

2. **Path filtering:** Only runs when API-related files change

3. **Schemathesis settings:**
   - `--hypothesis-max-examples=20`: Reasonable test count for CI speed
   - `--hypothesis-seed=42`: Reproducible tests
   - `--workers 1`: Avoid race conditions with single server
   - `--checks all`: Run all built-in checks (status codes, content type, schema)

4. **Gate job:** `api-contracts-success` provides single status check for branch protection

5. **JUnit reporting:** Test results appear in PR checks with detailed failures

**Expected issues and fixes:**

1. **Auth-protected endpoints fail:** Schemathesis can't authenticate.
   - Fix: Add `x-skip` in OpenAPI spec or use Schemathesis hooks (advanced)
   - Alternative: Mark auth endpoints with 401 as valid response in spec

2. **Random data causes validation errors:** Schemathesis generates random payloads.
   - Fix: Add proper constraints in OpenAPI schemas (minLength, maxLength, pattern, enum)

3. **Server-side validation rejects requests:** Expected behavior.
   - Fix: Ensure 400 responses are documented in spec

**For auth endpoints:**
Add stateful testing config or skip endpoints that require authentication:

```yaml
# In openapi.yaml, for endpoints that require auth:
/api/user/profile:
  get:
    security:
      - cookieAuth: []
    responses:
      '401':
        description: Not authenticated
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/Error'
```

Schemathesis will test that unauthenticated requests return 401, which is correct behavior.
