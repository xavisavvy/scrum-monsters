     - eventLoopBlockingDetected: false
     - estimatedBandwidthMB: 0.5-1.0
     - wsConnectionsPeak: users
     - sampleCount: 10
     - durationMs: 10000
     - samples: [] (empty array is fine for synthetic)

   - Steady State scenario (60s sustained):
     - peakRSSMB: 120-140 (stabilized)
     - peakHeapMB: 85-100
     - avgHeapMB: 70-85
     - avgCPUPercent: 15-25 (normal operation)
     - peakCPUPercent: 40-55
     - eventLoopUtilization: 0.15-0.25
     - eventLoopPeakUtilization: 0.35-0.45
     - eventLoopBlockingDetected: false
     - estimatedBandwidthMB: 3.0-5.0 (60s of messages)
     - wsConnectionsPeak: users
     - sampleCount: 60
     - durationMs: durationSeconds * 1000
     - samples: [] (empty array)

   - Teardown scenario (10s drain):
     - peakRSSMB: 110-125 (declining)
     - peakHeapMB: 75-90
     - avgHeapMB: 65-80
     - avgCPUPercent: 5-10 (idle cleanup)
     - peakCPUPercent: 15-25
     - eventLoopUtilization: 0.05-0.10
     - eventLoopPeakUtilization: 0.15-0.25
     - eventLoopBlockingDetected: false
     - estimatedBandwidthMB: 0.1-0.3

     - sampleCount: 10
     - durationMs: 10000

   - peakCPUPercent: max across all 3 scenarios

   - eventLoopUtilization: steady state value
   - estimatedBandwidthMBPerMonth: calculated using same formula from run-profile.ts (bandwidthPerSecond * 3600 * 730 * 0.1)
