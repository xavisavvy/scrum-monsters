  <action>
Create `server/events/EventBus.ts` with a typed EventBus class extending Node.js EventEmitter.

The EventBus must:
1. Extend Node.js EventEmitter
2. Override `emit<K>()` with typed version accepting only valid event names and matching payloads
3. Override `on<K>()` with typed version for type-safe listeners
4. Override `once<K>()` with typed version for one-time listeners
5. Override `off<K>()` with typed version for removing listeners
6. Support async listeners (fire-and-forget pattern - don't await Promise results in emit)

Implementation pattern from research:
```typescript
import { EventEmitter } from 'events';
import { DomainEventMap, DomainEventName } from './eventTypes';

/**
 * Strongly-typed EventBus for server-side domain coordination.
 *
 * This EventBus is for INTERNAL server events only, NOT for client communication.
 * Socket.IO handles client-server events separately.
 *
 * Listeners can be async but are NOT awaited (fire-and-forget pattern).
 * Each listener handles its own timing and error handling.
 */
export class EventBus extends EventEmitter {
  emit<K extends DomainEventName>(
    event: K,
    payload: DomainEventMap[K]
  ): boolean {
    return super.emit(event, payload);
  }

  on<K extends DomainEventName>(
    event: K,
    listener: (payload: DomainEventMap[K]) => void | Promise<void>
  ): this {
    return super.on(event, listener);
  }

  once<K extends DomainEventName>(
    event: K,
    listener: (payload: DomainEventMap[K]) => void | Promise<void>
  ): this {
    return super.once(event, listener);
  }

  off<K extends DomainEventName>(
    event: K,
    listener: (payload: DomainEventMap[K]) => void | Promise<void>
  ): this {
    return super.off(event, listener);
  }
}
```

Add helper method for debugging:
```typescript
  /**
   * Get all registered event names (for debugging)
   */
  getRegisteredEvents(): DomainEventName[] {
    return this.eventNames() as DomainEventName[];
  }
```

Export the EventBus class as the default and named export.
