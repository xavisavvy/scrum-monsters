<task type="auto">
  <name>Task 1: Add Blackbox Exporter and Prometheus alert rules</name>
  <files>docker/blackbox/blackbox.yml, docker/prometheus/alerts.yml, docker/prometheus/prometheus.yml, docker-compose.prod.yml</files>
  <action>
**1. Create `docker/blackbox/blackbox.yml`:**

```yaml
modules:
  https_2xx:
    prober: http
    timeout: 10s
    http:
      valid_http_versions: ["HTTP/1.1", "HTTP/2.0"]
      valid_status_codes: [200]
      method: GET
      tls_config:
        insecure_skip_verify: false
```

**2. Create `docker/prometheus/alerts.yml`:**

```yaml
groups:
  - name: tls
    rules:
      - alert: TLSCertExpiringSoon
        expr: (probe_ssl_earliest_cert_expiry{job="blackbox-tls"} - time()) / 86400 < 14
        for: 1h
        labels:
          severity: warning
        annotations:
          summary: "TLS certificate expires in {{ $value | humanizeDuration }}"
          description: "Certificate for {{ $labels.instance }} expires in less than 14 days."

      - alert: TLSCertExpiryCritical
        expr: (probe_ssl_earliest_cert_expiry{job="blackbox-tls"} - time()) / 86400 < 7
        for: 1h
        labels:
          severity: critical
        annotations:
          summary: "TLS certificate expires in {{ $value | humanizeDuration }}"
          description: "Certificate for {{ $labels.instance }} expires in less than 7 days."
```

**3. Update `docker/prometheus/prometheus.yml`:**

Add `rule_files` section and `blackbox-tls` scrape job. The existing `scrumquest` job must remain unchanged. Add after the existing scrape_configs entry:

```yaml
rule_files:
  - '/etc/prometheus/alerts.yml'
```

Add to `scrape_configs`:

```yaml
  - job_name: 'blackbox-tls'
    metrics_path: /probe
    params:
      module: [https_2xx]
    static_configs:
      - targets:
          - https://scrummonsters.com
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: blackbox-exporter:9115
```

**4. Update `docker-compose.prod.yml`:**

Add the `blackbox-exporter` service (before the `volumes:` section):

```yaml
  blackbox-exporter:
    image: prom/blackbox-exporter:latest
    restart: unless-stopped
    ports:
      - "127.0.0.1:9115:9115"
    volumes:
      - ./docker/blackbox/blackbox.yml:/config/blackbox.yml:ro
    command:
      - '--config.file=/config/blackbox.yml'
    deploy:
      resources:
        limits:
          memory: 32M
        reservations:
          memory: 16M
```

Also update the `prometheus` service to mount the alerts file. Add this to the prometheus volumes list:

```yaml
      - ./docker/prometheus/alerts.yml:/etc/prometheus/alerts.yml:ro
```

Memory budget: Blackbox Exporter adds ~10-15 MB. Total stack stays under 650 MB of 1024 MB.

NOTE on DNS resolution: If Blackbox Exporter cannot resolve scrummonsters.com from inside Docker, the fallback is to add `network_mode: host` or add `dns: 8.8.8.8` to the service. Check `probe_success` metric after deployment.
