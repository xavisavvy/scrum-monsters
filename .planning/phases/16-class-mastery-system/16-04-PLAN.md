**Create `client/src/lib/stores/useClassMastery.tsx`:**

Follow the useProgression store pattern exactly. Use Zustand with subscribeWithSelector middleware.

State interface:
```typescript
interface ClassMasteryState {
  // Per-class mastery data: avatarClass → { classXP, currentTier }
  masteryData: Record<string, { classXP: number; currentTier: MasteryTier }>;

  // Pending tier-up notification (for celebration/toast)
  pendingTierUp: {
    avatarClass: string;
    oldTier: MasteryTier;
    newTier: MasteryTier;
  } | null;

  // Actions
  handleXPAwarded: (data: { playerId: string; avatarClass: string; amount: number; source: string; newTotal: number }) => void;
  handleTierUp: (data: { playerId: string; avatarClass: string; oldTier: string; newTier: string }) => void;
  handleSync: (data: { playerId: string; masteryData: Record<string, { classXP: number; currentTier: string }> }) => void;
  clearTierUp: () => void;
  reset: () => void;

  // Computed helpers
  getMasteryForClass: (avatarClass: string) => { classXP: number; currentTier: MasteryTier } | null;
  getProgressToNextTier: (avatarClass: string) => { current: number; needed: number; percentage: number; currentTier: MasteryTier; nextTier: MasteryTier | null };
}
```

Implementation:
- `handleXPAwarded`: Update masteryData[avatarClass].classXP to newTotal, recalculate tier using client-side ClassMasteryXPCurve (import from @shared/classMasteryTypes)
- `handleTierUp`: Set pendingTierUp with avatarClass, oldTier, newTier
- `handleSync`: Replace entire masteryData with synced data
- `clearTierUp`: Set pendingTierUp to null
- `reset`: Clear all mastery data
- `getMasteryForClass`: Return masteryData[avatarClass] or null
- `getProgressToNextTier`: Use ClassMasteryXPCurve to calculate progress to next tier

In the socket event setup section (where progression:* handlers are), add:
```typescript
socket.on('class_mastery:xp_awarded', (data) => {
  const { currentPlayer } = useGameState.getState();
  if (currentPlayer && data.playerId === currentPlayer.id) {
    useClassMastery.getState().handleXPAwarded(data);
  }
});

socket.on('class_mastery:tier_up', (data) => {
  const { currentPlayer } = useGameState.getState();
  if (currentPlayer && data.playerId === currentPlayer.id) {
    useClassMastery.getState().handleTierUp(data);
  }
});

socket.on('class_mastery:sync', (data) => {
  const { currentPlayer } = useGameState.getState();
  if (currentPlayer && data.playerId === currentPlayer.id) {
    useClassMastery.getState().handleSync(data);
  }
});
```

Import useClassMastery at the top of useWebSocket.tsx.
Only process events for the current player (mastery is private data, same as XP).
