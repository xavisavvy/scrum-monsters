**Add ClassMasteryManager dependency** to CombatManagerDeps interface:
```typescript
classMasteryManager?: {
  getMasteryMultiplier: (lobbyId: string, playerId: string, avatarClass: AvatarClass | null) => number;
  getUnlockedAbilities: (lobbyId: string, playerId: string, avatarClass: AvatarClass | null) => string[];
};
```

Use an optional interface (not full ClassMasteryManager import) to avoid tight coupling. The dependency is injected through the existing deps pattern.

Store the reference in the constructor:
```typescript
private readonly classMasteryManager: CombatManagerDeps['classMasteryManager'];
```

**Modify `getClassBaseDamage`** to accept an optional mastery multiplier:
Change the method signature to:
```typescript
private getClassBaseDamage(avatarClass: AvatarClass | null | undefined, masteryMultiplier: number = 1.0): number
```

Apply the multiplier at the end: `return Math.floor(baseDamage * masteryMultiplier);`

**Modify `attackBoss` method:**
Before calling `getClassBaseDamage`, get the mastery multiplier:
```typescript
const masteryMultiplier = this.classMasteryManager?.getMasteryMultiplier(lobbyId, playerId, playerClass) ?? 1.0;
const baseDamage = this.getClassBaseDamage(playerClass, masteryMultiplier);
```

**Modify `applyTeamAttackDamage` method** (the team attack calculation):
For each fighting player, get their mastery multiplier when calculating per-player damage:
```typescript
const masteryMultiplier = this.classMasteryManager?.getMasteryMultiplier(lobbyId, player.playerId, playerClass) ?? 1.0;
baseDamage += this.getClassBaseDamage(playerClass, masteryMultiplier);
```

**Modify `attackMinion` method:**
Same pattern as attackBoss — get mastery multiplier before calculating damage:
```typescript
const masteryMultiplier = this.classMasteryManager?.getMasteryMultiplier(lobbyId, playerId, playerClass) ?? 1.0;
const baseDamage = this.getClassBaseDamage(playerClass, masteryMultiplier);
```

**Add `canUseClassAbility` public method:**
```typescript
public canUseClassAbility(lobbyId: string, playerId: string, abilityId: string): boolean {
  const playerClass = this.getPlayerClass?.(lobbyId, playerId);
  if (!playerClass || !this.classMasteryManager) return false;
  const unlockedAbilities = this.classMasteryManager.getUnlockedAbilities(lobbyId, playerId, playerClass);
  return unlockedAbilities.includes(abilityId);
}
```

This method will be used by Phase 18 (Class Abilities) to check if a player has unlocked an ability. For now, it's a public API that ability usage can check against.

**IMPORTANT:** All changes must be backward-compatible. When classMasteryManager is undefined (not wired yet), damage calculations use the default 1.0 multiplier — exactly the same as current behavior. Existing tests should NOT break.
