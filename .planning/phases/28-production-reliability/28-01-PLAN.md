  **Enhanced graceful shutdown** — Replace the existing `gracefulShutdown` function in server/index.ts with:

  1. **Set forced exit timeout** (30s) at the start — prevents shutdown from hanging indefinitely. Use `.unref()` so it doesn't keep the event loop alive.
  2. **Emit `server_shutdown` event** to ALL connected WebSocket clients with `{ message: 'Server shutting down for maintenance', reconnectDelayMs: 30000 }`. Access `io` via `(server as any).io`.
  3. **Wait 2 seconds** for clients to receive the notification (`await new Promise(resolve => setTimeout(resolve, 2000))`).
  4. **Then proceed** with existing cleanup order: WebSocket intervals cleanup → Redis shutdown → Database pool close → HTTP server close.
  5. **Clear the force exit timeout** and `process.exit(0)` on success.
  6. **Wrap in try-catch** — on error, log and `process.exit(1)`.

  The enhanced function should look like:
  ```typescript
  const gracefulShutdown = async (signal: string) => {
    console.log(`\n${signal} received, shutting down gracefully...`);

    // Force exit after 30s to prevent hanging (Kubernetes SIGKILL at 30s)
    const forceExitTimeout = setTimeout(() => {
      console.error('Shutdown timeout exceeded, forcing exit');
      process.exit(1);
    }, 30000);
    forceExitTimeout.unref(); // Don't keep event loop alive

    try {
      // 1. Notify all connected WebSocket clients
      const io = (server as any).io;
      if (io) {
        io.emit('server_shutdown', {
          message: 'Server shutting down for maintenance',
          reconnectDelayMs: 30000,
        });
        // Wait for clients to receive notification
        await new Promise(resolve => setTimeout(resolve, 2000));
      }

      // 2. Stop accepting new connections and clean up intervals
      if ((server as any).cleanupWebSocket) {
        (server as any).cleanupWebSocket();
      }

      // 3. Close Redis connections
      await shutdownRedis();

      // 4. Close database connections
      if (storage instanceof PgStorage) {
        console.log("Closing database connections...");
        await storage.close();
        console.log("Database connections closed");
      }

      // 5. Close HTTP server (stops accepting new requests)
      await new Promise<void>((resolve) => {
        server.close(() => resolve());
      });

      clearTimeout(forceExitTimeout);
      console.log('Server closed');
      process.exit(0);
    } catch (error) {
      console.error('Error during shutdown:', error);
      process.exit(1);
    }
  };
  ```
