Output: Split health endpoints in server/routes.ts, updated K8s probe configuration in deployment manifests.

  1. **`/api/health/livez`** — Simple heartbeat, NEVER checks database. Kubernetes liveness probe. Failure = restart container.
  ```typescript

    res.json({ status: 'ok', timestamp: new Date().toISOString() });
  });
  ```

  2. **`/api/health/readyz`** — Comprehensive readiness check INCLUDING database. Kubernetes readiness probe. Failure = stop routing traffic to this pod.
  ```typescript
  app.get('/api/health/readyz', async (_req, res) => {
    const checks: Record<string, { healthy: boolean; message?: string }> = {};

    // Check database connectivity
    if (storage instanceof PgStorage) {
      try {
        const sql = storage.getSql();
        await Promise.race([
          sql`SELECT 1 as health`,
          new Promise((_, reject) =>
            setTimeout(() => reject(new Error('Database health check timeout (3s)')), 3000)
          ),
        ]);
        checks.database = { healthy: true };
      } catch (error) {
        checks.database = {
          healthy: false,
          message: error instanceof Error ? error.message : 'Unknown database error',
        };
      }
    } else {
      checks.database = { healthy: true, message: 'in-memory storage' };
    }

    const isReady = Object.values(checks).every((check) => check.healthy);
    const status = isReady ? 200 : 503;

    res.status(status).json({
      status: isReady ? 'ok' : 'not_ready',
      checks,
      timestamp: new Date().toISOString(),
    });
  });
  ```

  3. **`/api/health`** — Backward-compatible endpoint. Delegates to readyz logic (same response format). This preserves any external monitoring or scripts that use `/api/health`.

  ```typescript
        await Promise.race([
          sql`SELECT 1 as health`,

      } catch (error) {
        checks.database = {
          healthy: false,
          message: error instanceof Error ? error.message : 'Unknown database error',
        };
  ```
