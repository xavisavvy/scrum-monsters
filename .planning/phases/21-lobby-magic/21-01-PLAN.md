<task type="auto">
  <name>Task 2: Wire rate limiters into routes, fix open redirect, configure trust proxy</name>
  <files>server/routes.ts, server/index.ts</files>
  <action>
**In `server/index.ts`:**
Add `app.set('trust proxy', 1)` BEFORE the session middleware (after `app.use(express.urlencoded(...))`). This tells Express to trust the first proxy hop (Kubernetes ingress / Cloudflare) for correct client IP in X-Forwarded-For headers.

**In `server/routes.ts`:**

1. Import rate limiters:
```typescript
import { authLimiter, profileLimiter, apiLimiter } from './middleware/rateLimiter.js';
```

2. Apply rate limiters BEFORE route handlers are mounted, inside `registerRoutes()`. Add these BEFORE the existing `app.use("/api/auth", authRoutes)` line:

```typescript
// Rate limiting (applied before route handlers)
app.use('/api/auth/login', authLimiter);
app.use('/api/auth/register', authLimiter);
app.use('/api/user', profileLimiter);
app.use('/api', apiLimiter);
```

Note: Apply authLimiter ONLY to /login and /register (not /google, /github OAuth routes — those use OAuth state parameter for CSRF protection and should not be rate-limited as strictly).

3. Fix the open redirect in `/join/:lobbyId` handler. Replace:
```typescript
app.get('/join/:lobbyId', (req, res) => {
  const { lobbyId } = req.params;
  // Redirect to frontend with lobby ID
  res.redirect(`/?join=${lobbyId}`);
});
```

With:
```typescript
app.get('/join/:lobbyId', (req, res) => {
  const { lobbyId } = req.params;
  // Validate: 6 uppercase alphanumeric chars (matches generateLobbyCode output)
  if (!/^[A-Z0-9]{6}$/i.test(lobbyId)) {
    return res.redirect('/?error=invalid-invite');
  }
  res.redirect(`/?join=${encodeURIComponent(lobbyId.toUpperCase())}`);
});
```

Use case-insensitive regex (`/i` flag) so users can type lowercase in URLs, but normalize to uppercase. Use `encodeURIComponent` for defense in depth.
  </action>
