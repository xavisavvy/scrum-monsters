Replace all security-sensitive Math.random() usages with crypto.randomBytes() in server code. Purpose: Close CodeQL insecure randomness alerts. Math.random() is not cryptographically secure — its output is predictable with enough samples, making lobby codes, player IDs, and tokens guessable by attackers.

Output: All security-sensitive ID generation uses cryptographic randomness.
