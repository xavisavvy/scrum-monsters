Install csrf-sync:
```bash
npm install csrf-sync
```

Create `server/middleware/csrf.ts`:

```typescript
import { csrfSync } from 'csrf-sync';

const { generateToken, csrfSynchronisedProtection } = csrfSync({
  getTokenFromRequest: (req) => req.headers['x-csrf-token'] as string,
  size: 128,
});

export { generateToken, csrfSynchronisedProtection };
```

Key design decisions:
- Read token from `x-csrf-token` header (SPA pattern — React sends headers, not form bodies)
- Session-bound token (csrf-sync uses express-session which is already configured)
- Do NOT install cookie-parser — csrf-sync uses session storage, not cookies
- Default behavior: csrfSynchronisedProtection skips GET/HEAD/OPTIONS (safe methods)

**In `server/routes.ts`:**

1. Import CSRF functions:
```typescript
import { generateToken, csrfSynchronisedProtection } from './middleware/csrf.js';
```

2. Add CSRF token endpoint (GET — no CSRF protection needed on GET):
```typescript
// CSRF token endpoint
app.get('/api/csrf-token', (req, res) => {
  const token = generateToken(req);
  res.json({ csrfToken: token });
});
```
Place this AFTER session middleware is available but BEFORE route handlers.

3. Apply CSRF protection to state-changing routes. Add AFTER rate limiters but BEFORE route mounting:
```typescript
// CSRF protection on state-changing endpoints
app.use('/api/auth/login', csrfSynchronisedProtection);
app.use('/api/auth/register', csrfSynchronisedProtection);
app.use('/api/auth/logout', csrfSynchronisedProtection);
app.use('/api/user', csrfSynchronisedProtection);
```

Do NOT apply to:
- OAuth routes (/api/auth/google, /api/auth/github) — they use OAuth state parameter
- GET endpoints — csrfSynchronisedProtection already skips safe methods
- WebSocket events — not HTTP, already protected by CORS origin checking

**Create `client/src/lib/csrfToken.ts`:**

```typescript
let csrfToken: string | null = null;

export async function fetchCsrfToken(): Promise<string> {
  const response = await fetch('/api/csrf-token', {
    credentials: 'include',
  });
  const data = await response.json();
  csrfToken = data.csrfToken;
  return csrfToken;
}

export function getCsrfToken(): string | null {
  return csrfToken;
}

export function getCsrfHeaders(): Record<string, string> {
  return csrfToken ? { 'x-csrf-token': csrfToken } : {};
}
```
