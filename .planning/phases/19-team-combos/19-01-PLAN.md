**GREEN PHASE — Implement ComboManager** in `server/domains/ComboManager.ts`:

```typescript
export interface ComboManagerDeps {
  eventBus: ScopedEventBus;
  combatManager: {
    applyComboMultiplier: (lobbyId: string, comboId: string, damage: number) => void;
  };
  getPlayerClass: (lobbyId: string, playerId: string) => AvatarClass | null;
  getVotingStartTime: (lobbyId: string) => number | null;
}
```

**Internal state:**
- `recentAbilities: Map<lobbyId, AbilityTimestamp[]>` — tracks recent ability uses with timestamps
- `comboCooldowns: Map<lobbyId, Map<comboId, { expiresAt: number }>>` — per-combo cooldowns
- `consensusUsed: Set<string>` — tracks lobbyId+ticketId combos to prevent re-trigger

**Constructor subscriptions:**
- `eventBus.on('ability:used', this.handleAbilityUsed.bind(this))`
- `eventBus.on('estimation:full_consensus_reached', this.handleFullConsensus.bind(this))`

**handleAbilityUsed(payload):**
1. Get player class via deps.getPlayerClass
2. Record ability timestamp: { playerId, playerClass, timestamp: Date.now() }
3. Clean old timestamps (>3s)
4. Check each CLASS_COMBOS definition:
   a. Skip if combo on cooldown
   b. Check if trigger conditions met: for each trigger in combo.triggers, check if recentAbilities has entries for both classA and classB (from different players) within window
   c. On match: calculate damage (baseDamage * damageMultiplier), start cooldown, call deps.combatManager.applyComboMultiplier, emit combo:triggered event

**handleFullConsensus(payload):**
1. Build guard key: `${lobbyId}:${ticketId}`
2. Skip if already in consensusUsed set
3. Add to consensusUsed
4. Get voting start time via deps.getVotingStartTime
5. Calculate voting duration (Date.now() - startTime, default 30000 if unknown)
6. Calculate multiplier using linear interpolation between CONSENSUS_MIN_MULTIPLIER and CONSENSUS_MAX_MULTIPLIER based on voting speed
7. Calculate damage: CONSENSUS_ULTIMATE_BASE_DAMAGE * multiplier
8. Call deps.combatManager.applyComboMultiplier with 'consensus_ultimate' id
9. Emit combo:consensus_ultimate event

**Public methods:**
- `resetCombos(lobbyId: string)` — clear recentAbilities, comboCooldowns for lobby
- `cleanupLobby(lobbyId: string)` — resetCombos + remove consensusUsed entries for lobby

**Register domain events** in `server/events/eventTypes.ts`:
