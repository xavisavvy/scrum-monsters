<feature>
  <name>Vote Casting and Consensus Detection</name>
  <files>server/domains/EstimationManager.ts, server/domains/EstimationManager.test.ts</files>
  <behavior>
**Vote Casting Rules:**
- castVote(lobbyId, playerId, team, vote) adds vote to team's vote Map
- Vote must be valid Fibonacci (1,2,3,5,8,13,21) or '?' for abstain
- Player must be in eligibleVoters Set for their team
- Spectators cannot vote (not in eligibleVoters)
- Throws EstimationNotActiveError if no active estimation for lobby
- Throws VoteNotEligibleError if player not eligible
- Throws InvalidVoteValueError if vote not valid Fibonacci or '?'
- Emits 'estimation:vote_cast' event on successful vote

**Eligible Voter Management:**
- addEligibleVoter(lobbyId, playerId, team) adds player to team's eligibleVoters
- removeEligibleVoter(lobbyId, playerId) removes from their team and removes their vote
- When vote removed, recalculate consensus

**Consensus Detection (per CONTEXT.md - strict all-same-value):**
- checkConsensus called after every vote cast
- All eligible voters must have voted
- All numeric votes must be the same value (abstentions '?' don't block consensus)
- If team has no eligible voters, mark as skipped (hasConsensus = true, consensusValue = undefined)
- When consensus reached: set hasConsensus = true, consensusValue = the agreed value
- Emit 'estimation:team_consensus_reached' event
- Check if both teams have consensus -> emit 'estimation:full_consensus_reached' after 2.5s pause

**Test Cases:**
1. castVote with valid Fibonacci -> vote stored, event emitted
2. castVote with '?' (abstain) -> vote stored as abstention
3. castVote with invalid value -> throws InvalidVoteValueError
4. castVote when no estimation active -> throws EstimationNotActiveError
5. castVote when player not eligible -> throws VoteNotEligibleError
6. Consensus reached when all vote same value -> hasConsensus true, event emitted
7. No consensus when votes differ -> hasConsensus false
8. Abstentions don't block consensus (3 vote 5, 1 votes '?' = consensus at 5)
9. Team with no voters is skipped -> consensus automatically true
10. Both teams consensus -> full consensus event after delay
11. Vote change triggers re-check (was 5, now 8 -> consensus may break)
12. Removing eligible voter removes their vote and rechecks consensus
  </behavior>
