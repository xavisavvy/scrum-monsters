  <behavior>
**Timer Start Behavior (per CONTEXT.md):**
- Timer starts on FIRST vote for a team (not on ticket load)
- Default duration: 60 seconds (DEFAULT_VOTING_DURATION constant)
- Store timerHandle, timerStartedAt, timerDurationMs in TeamVoteState
- Emit 'estimation:timer_started' with lobbyId, team, durationMs, startedAt

**Timer Expiry Behavior:**
- When timer expires, reveal all votes cast
- Set team's phase to 'revealed'
- If no votes cast: emit 'estimation:timer_expired_no_votes', stay in voting phase
- If votes cast: emit 'estimation:timer_expired_reveal', enter revealed phase

**Host Controls:**
- pauseTimer(lobbyId, team, hostId): Clear timer, store remaining time, emit 'estimation:timer_paused'
- resumeTimer(lobbyId, team, hostId): Restart timer with remaining time, emit 'estimation:timer_resumed'
- extendTimer(lobbyId, team, additionalMs, hostId): Add time to current/paused timer, emit 'estimation:timer_extended'

**Timer Cleanup (CRITICAL - prevents memory leaks):**
- cleanupLobby must clear ALL timer handles
- Consensus reached clears that team's timer (no longer needed)
- Track all timers in timerHandle field of TeamVoteState

**Test Cases (TDD):**
1. First vote starts timer -> timerStartedAt set, timerHandle exists
2. Timer started event emitted with correct payload
3. Second vote does NOT restart timer -> same timerStartedAt
4. Timer expiry with votes -> phase = 'revealed', event emitted
5. Timer expiry with no votes -> phase stays 'voting', different event
6. pauseTimer clears handle, stores remaining time
7. resumeTimer restarts with remaining time
8. extendTimer adds time to running timer
9. extendTimer adds time to paused timer
10. cleanupLobby clears all timers
11. Consensus reached clears timer for that team
12. Dev timer independent of QA timer (one starts, other doesn't)
