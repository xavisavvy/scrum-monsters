<feature>
  <name>Channel-Based Revival System</name>
  <files>server/domains/CombatManager.ts, server/domains/CombatManager.test.ts</files>
  <behavior>
Start revival:
- startRevival(lobbyId, reviverId, targetId) initiates channel
- Only healer classes can revive (cleric, paladin, bard)
- Reviver must be in 'fighting' state
- Target must be in 'downed' state
- Target must NOT have hasBeenRevived=true (one revive per fight)
- Throws RevivalNotAllowedError for invalid attempts
- Creates RevivalSession with startedAt, channelDurationMs=2500
- Emits combat:revival_started with durationMs
- Starts setInterval to tick every 100ms for completion check
- Returns true on success, false if conditions not met

Revival tick:
- tickRevival(sessionKey) runs every 100ms
- Check if reviver still fighting (interrupt if downed)
- Check if target still downed (cancel if died/revived)
- Check if elapsed time >= channelDurationMs
- Complete revival if duration reached

Complete revival:
- completeRevival(sessionKey) finishes the channel
- Clear target's down timer (prevent ghost transition)
- Set target HP to 50% of maxHp
- Set target combatState='fighting', isDowned=false
- Set target hasBeenRevived=true (one revive limit)
- Clear interval handle
- Remove from revivalSessions Map
- Emit combat:player_revived

Cancel revival:
- cancelRevival(reviverId, reason) interrupts channel
- Clear interval handle
- Remove from revivalSessions Map
- Emit combat:revival_cancelled with reason
- Reasons: 'took_damage', 'moved', 'player_left', 'target_died', 'permanent_down'

Damage interrupts revival:
- When reviver takes damage (in applyDamageToPlayer), cancel their revival
- Check revivalSessions for any session where reviver is channeling
- Call cancelRevival with reason='took_damage'

Cleanup:
- Update cleanupLobby to clear all revival sessions for the lobby
- Clear interval handles to prevent memory leaks

Test cases:
- startRevival creates RevivalSession
- startRevival emits combat:revival_started
- Only healer classes can start revival
- Non-healer throws RevivalNotAllowedError
- Cannot revive already-revived player (hasBeenRevived=true)
- Cannot revive ghost (only downed)
- Revival completes after 2.5 seconds
- Completed revival sets HP to 50%
- Completed revival sets hasBeenRevived=true
- Completed revival emits combat:player_revived
- Damage to reviver cancels revival
- Cancel emits combat:revival_cancelled with reason
- Target dying (permanent down) cancels revival
- Cleanup clears all revival sessions
- Down timer cleared when revival completes
  </behavior>
