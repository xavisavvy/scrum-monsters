<feature>
  <name>Combat Initialization & Boss Damage System</name>
  <files>server/domains/CombatManager.ts, server/domains/CombatManager.test.ts</files>
  <behavior>
Combat initialization:
- initializeCombat(lobbyId, players, ticketIndex) creates LobbyCombatState
- Boss HP = BASE_HP_PER_PLAYER (1000) * active player count (exclude spectators)
- Ticket difficulty: multiply by (1 + ticketIndex * 0.2) for dungeon crawl feel
- Players start with maxHp=100, combatState='fighting', hasBeenRevived=false
- Emits combat:battle_initialized with bossId and bossMaxHp

Player attacks boss:
- playerAttackBoss(lobbyId, playerId) returns damage dealt
- Base damage determined by avatar class (getClassBaseDamage)
- Damage multiplied by battleModifier (starts at 1.0)
- Updates threat table (playerId -> cumulative damage)
- Emits combat:boss_damaged with damage and new HP
- Throws CombatNotActiveError if no combat
- Throws PlayerNotInCombatError if player not in 'fighting' state

Boss enrage:
- When HP drops to <= 50% maxHp, isEnraged becomes true
- Emits combat:boss_enraged with message

Boss defeat:
- When HP <= 0, emit combat:boss_defeated
- Clear attack timer if running (placeholder for Plan 04-03)

Test cases:
- initializeCombat with 3 players -> boss HP = 3000
- initializeCombat with ticketIndex=4 -> boss HP multiplied by 1.8
- initializeCombat filters out spectators from player count
- playerAttackBoss reduces boss HP by class damage * modifier
- playerAttackBoss updates threat table
- playerAttackBoss emits combat:boss_damaged
- Boss enrages when HP drops below 50%
- Boss defeated emits event when HP reaches 0
- Throws on attack when no combat active
- Throws on attack when player is downed/ghost
  </behavior>
