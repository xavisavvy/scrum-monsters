<feature>
  <name>Boss Attack AI System</name>
  <files>server/domains/CombatManager.ts, server/domains/CombatManager.test.ts</files>
  <behavior>
Boss attack loop:
- startBossAttackLoop(lobbyId) starts recursive setTimeout
- First attack after BOSS_INITIAL_ATTACK_DELAY_MS (3s grace period)
- Subsequent attacks at variable intervals: base * (1 +/- variance)
  - Normal: 5000ms base, ±30% variance (3500-6500ms)
  - Enraged: 3000ms base, ±30% variance (2100-3900ms)
- Loop stops when boss HP <= 0 or combat ends

Attack type selection:
- selectAttackType(isEnraged) returns 'light' | 'heavy' | 'special'
- Normal distribution: light 60%, heavy 30%, special 10%
- Enraged distribution: light 40%, heavy 35%, special 25%

AoE vs single-target:
- Random chance each attack: 15% normal, 25% enraged
- AoE hits ALL players with combatState='fighting' (filter out downed/ghost)
- Single-target uses threat-based selection

Threat-based targeting:
- selectThreatTarget returns highest-threat alive player (70% chance)
- 20% chance for second-highest threat
- 10% chance for random alive player
- Falls back to random if no threat history

Attack execution:
- Light attacks: instant damage (LIGHT_DAMAGE=25)
- Heavy/special attacks: telegraph first
  - Emit combat:boss_telegraph with message and delayMs (1000ms)
  - After delay, apply damage

Telegraph messages:
- Heavy: "Boss winds up a heavy blow..."
- Special: "Boss is charging a devastating attack..."

Test cases:
- startBossAttackLoop schedules first attack after 3s
- Attack loop reschedules with variable timing
- Enraged boss attacks faster (3s base vs 5s)
- selectAttackType returns valid attack type
- AoE attack damages all fighting players
- AoE attack does NOT damage downed/ghost players
- Threat targeting favors highest damage dealer
- Telegraph emitted before heavy/special damage
- Attack loop stops on boss defeat
- Attack loop stops on combat cleanup
  </behavior>
