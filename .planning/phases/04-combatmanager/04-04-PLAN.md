<feature>
  <name>Player Health & Down System</name>
  <files>server/domains/CombatManager.ts, server/domains/CombatManager.test.ts</files>
  <behavior>
Player takes damage:
- applyDamageToPlayer(lobbyId, playerId, damage) reduces HP
- HP cannot go below 0
- Emits combat:player_damaged with damage and new HP
- If HP reaches 0, call downPlayer

Down mechanics:
- downPlayer(lobbyId, playerId) transitions to downed state
- Set combatState='downed', isDowned=true, downedAt=Date.now()
- Emits combat:player_downed with countdownSeconds=10
- Starts 10-second timer (DOWN_TIMER_MS)
- After timer expires, call permanentlyDownPlayer

Permanent down (ghost mode):
- permanentlyDownPlayer(lobbyId, playerId) transitions to ghost
- Set combatState='ghost'
- Emits combat:player_permanently_downed with message
- Cancel any revival attempts targeting this player
- Ghost players cannot attack, heal, or be revived

Active healing:
- playerHealTeammate(lobbyId, healerId, targetId) heals during combat
- Only healer classes can heal (cleric, paladin, bard)
- Throws NotHealerClassError if non-healer tries to heal
- Healer must be in 'fighting' state
- Target must be in 'fighting' state (cannot heal downed/ghost)
- Heals HEAL_AMOUNT (25 HP), capped at maxHp
- Emits combat:player_healed with amounts
- No cooldown (spam allowed per CONTEXT.md)

Test cases:
- applyDamageToPlayer reduces HP by damage amount
- applyDamageToPlayer caps HP at 0
- applyDamageToPlayer emits combat:player_damaged
- Player downed when HP reaches 0
- Down emits combat:player_downed with countdown
- Down starts 10-second timer
- Timer expiry triggers permanent down
- Permanent down sets combatState='ghost'
- Permanent down emits event
- Permanent down cancels revival sessions
- Healer can heal teammate
- Non-healer cannot heal (throws NotHealerClassError)
- Cannot heal downed or ghost players
- Healing capped at maxHp
- Healing emits combat:player_healed
  </behavior>
