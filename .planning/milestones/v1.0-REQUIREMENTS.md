# Requirements: ScrumQuest Domain Separation

**Defined:** 2026-02-01
**Core Value:** Focused estimation with engaging combat layer — voting distraction-free, waiting fun

## v1 Requirements

Requirements for this refactoring milestone. Each maps to roadmap phases.

### Architecture

- [x] **ARCH-01**: Create SessionManager handling lobby lifecycle, players, teams, host transfer
- [x] **ARCH-02**: Create EstimationManager handling tickets, voting, consensus, discussion
- [x] **ARCH-03**: Create CombatManager handling boss, player HP, damage, revival, battle modifiers
- [x] **ARCH-04**: Create EventBus for cross-domain coordination using Node.js EventEmitter
- [x] **ARCH-05**: Split Lobby type into SessionState, EstimationState, CombatState
- [x] **ARCH-06**: Define domain event types (session.*, estimation.*, combat.*)
- [x] **ARCH-07**: Replace lobby_updated with fine-grained domain events *(partial - 16 documented fallback emissions)*
- [x] **ARCH-08**: Update client stores to subscribe to domain-specific events *(partial - fallback handler retained)*
- [x] **ARCH-09**: Establish event listener cleanup contracts to prevent memory leaks
- [x] **ARCH-10**: Migrate timer ownership to respective domain managers

### Flow

- [x] **FLOW-01**: Implement estimation phase as distinct from battle phase
- [x] **FLOW-02**: Trigger battle entry on first vote submission
- [x] **FLOW-03**: Support players in mixed states (estimating vs fighting)
- [x] **FLOW-04**: Implement boss death wait state when voting incomplete
- [x] **FLOW-05**: Add 10s countdown for bonus damage after all voted
- [x] **FLOW-06**: Transition to discussion phase after countdown/battle ends
- [x] **FLOW-07**: Maintain vote changeability during discussion phase

### Integration

- [x] **INTG-01**: Update socketHandlers.ts to route events through domain managers *(partial - most migrated)*
- [x] **INTG-02**: Preserve reconnection functionality across domain split
- [x] **INTG-03**: Maintain spectator boss-side combat behavior *(implemented as minion system)*
- [x] **INTG-04**: Keep existing team competition stats working
