## Phases

### Phase 30: Logging Cleanup

**Goal**: Migrate console.log to Pino structured logging and enforce with ESLint
**Depends on**: Phase 29
**Plans**: 2 plans

Plans:
- [x] 30-01: Migrate all 228 server-side console.log/warn/error to Pino structured logging
- [x] 30-02: Remove 166 client-side console.log statements and upgrade ESLint no-console to error

**Details:**
- Migrated 228 server console statements across 17 files using 5 logger types (httpLogger, socketLogger, gameLogger, dbLogger, authLogger)
- Applied structured object-first API format with appropriate log levels
- Removed 166 client-side console.log statements across 20 files
- Replaced debug logging with silent catch handlers for non-critical errors (audio autoplay)
- Preserved console.warn and console.error (allowed by ESLint)
- Added no-console:off exemptions for test files, k6 load tests, profiling scripts, and utility scripts
- ESLint no-console upgraded from warn to error — CI blocks any new console.log
