## Tech Debt

Minor items, none blocking:

1. **REQUIREMENTS.md checkboxes** — Phases 33-36 requirements still show unchecked/Pending in REQUIREMENTS.md. Documentation tracking gap; resolved during milestone archival.

2. **CI/CD does not `git pull` on VPS** (Medium) — `deploy-lightsail.yml` skips `git pull`, so compose file changes (new services, config files) require manual `deploy.sh` or SSH `git pull`. The manual `deploy.sh` does `git pull` first. This means infrastructure config changes only auto-deploy for the app image, not for compose/config changes.

3. **Grafana metric name mismatch** (Low) — Dashboard queries `scrumquest_nodejs_heap_used_bytes` but prom-client produces `scrumquest_nodejs_heap_size_used_bytes`. 1 of 10 panels shows "No data". Other 9 panels work correctly.

4. **Smoke tests use SSH curl** — Pragmatic adaptation to internal-only ports. Playwright smoke spec still exists for local/CI use.

5. **deploy.sh vs CI/CD not documented** (Info) — Both deployment paths exist without clear guidance on when to use which. Runbook documents deploy.sh only.

6. **No Terraform/IaC** — Infrastructure provisioned via console. Listed as future requirement (ADV-02).
