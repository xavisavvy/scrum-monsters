# Requirements: ScrumQuest

**Defined:** 2026-02-19
**Core Value:** Focused estimation that doesn't bore people — voting distraction-free, waiting fun

## v3.0 Requirements

Requirements for Production Optimization milestone. Each maps to roadmap phases.

### Hosting Optimization

- [x] **HOST-01**: User can see resource profiling report showing actual RAM, CPU, and bandwidth usage under load — Phase 29 (155MB peak, 21% CPU, 50 users)
- [x] **HOST-02**: User can see cost comparison of Replit tiers vs Railway, Render, Fly.io, and AWS Lightsail for ScrumQuest's measured resource needs — Phase 29 (9 tiers, 5 platforms)
- [x] **HOST-03**: User receives a recommendation for optimal hosting configuration at $5-20/mo budget — Phase 29 (AWS Lightsail $5/mo, 58% headroom)

### Database Setup

- [x] **DB-01**: User data persists across server restarts via PostgreSQL (XP, stats, class mastery, estimation history) — Phase 27 (PgStorage with full schema)
- [x] **DB-02**: PostgreSQL connection pool is configured with appropriate limits and timeouts — Phase 27 (configurable max/idle/connect)
- [x] **DB-03**: User sessions persist across server restarts via PostgreSQL session store — Phase 27 (connect-pg-simple, 15-min pruning)
- [x] **DB-04**: Environment variables are validated on startup with clear error messages for missing required values — Phase 27 (Zod schema, fail-fast)

### Production Reliability

- [x] **REL-01**: Server gracefully shuts down on SIGTERM/SIGINT (drains WebSocket connections, closes DB pool) — Phase 28 (30s timeout, client notification)
- [x] **REL-02**: Health check endpoint includes database connectivity verification — Phase 28 (livez/readyz split, 3s timeout)
- [x] **REL-03**: Server logs startup configuration (DB connected, pool size, env) for operational visibility — Phase 28 (Pino structured logging)

### Tech Debt

- [x] **DEBT-01**: shared/schema.ts compiles without TypeScript errors (fix Zod/Drizzle compatibility) — Phase 26 (Zod 4.3.6 upgrade)
- [x] **DEBT-02**: Production OG image replaces placeholder (1200x630 branded ScrumQuest image) — Phase 26 (Python PIL generation)
- [x] **DEBT-03**: Husky v10 deprecation warning resolved — Phase 26 (deleted .husky/_/ directory)
- [x] **DEBT-04**: Debug console.log removed from useSpriteAnimation.ts — Phase 26 (ESLint no-console warn)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Actual hosting migration | This milestone profiles and recommends; migration is a separate effort |
| Redis adapter / horizontal scaling | Only needed above 1000+ concurrent users |
| Serverless/Lambda deployment | WebSockets require long-lived connections, incompatible with serverless |
| Database read replicas | Premature optimization for current scale |
| Custom profiling tools | Clinic.js and built-in Node.js profiling are sufficient |
| VPC networking | Adds complexity with minimal security benefit at current scale |
